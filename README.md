# TREAGENT

팀 TREAGENT의 작업 저장소입니다.

## 현재 프로젝트

**대프리카 히든 퀘스트** (기획 단계)
- 더위를 피해 다니는 도시 탐험 게임. 날씨가 퀘스트 경로를 바꿉니다.
- 대상: 대구 거주 2030, 대구 방문 2030. 사계절 확장 (여름 대프리카 서바이벌, 가을·겨울 시즌).
- 선정 자산 (트랙 가중치, A안): 대구약령시, 대프리카, 이월드·83타워 (역사 테마는 시즌 후반).
- 트랙: AX 크리에이티브 트랙 (콘텐츠 & 뷰티).

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `기획/` | 기획서, 기획 요약, 취합본, 재사용 검토 |
| `자료/` | 조사 결과, 사례 분석, 인벤토리, 근거 검사 (`metadata.csv`, `tags.md`) |
| `디자인/` | 고객 여정 지도 등 디자인 산출물 |
| `발표/` | 발표 자료, 대본, 시연 영상 |
| `brand/` | 페르소나, 캐릭터(홍옥 다람쥐), 게임 요소, 한 장 기획서 |
| `storyboard/` | 훅 후보, 전환 문장, 스토리 구조 |
| `.claude/skills/` | 브랜드 스킬 (세계관 `worldview.md`, `SKILL.md`) |

## 작업 방법

- `main` 브랜치 하나에서 폴더로 나눠 작업합니다. 별도 주제 브랜치는 만들지 않습니다.
- 커밋과 푸시는 요청이 있을 때만 합니다.
- 공통 규칙(`CLAUDE.md`, `README.md`)은 `main`에서 고칩니다.

## 확인 필요 항목

- 팀 결정 항목(가중치 비율, 훅 테마 비율, 캐릭터 이름 등)은 각 문서의 `결정 필요`에 모아 둡니다.
- 근거가 불충분한 내용은 `[미검증]` 또는 `[확인 필요]`로 표시합니다.
