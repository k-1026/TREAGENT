- 걸은 길이 한 권의 이야기 책으로 남는 구조

## 팀

- 박민지
- 2명 추가 모집 중 (확정 전)

## 브랜치 구성

| 브랜치 | 폴더 | 내용 |
|---|---|---|
| `main` | - | README, CLAUDE.md (공통 규칙) |
| `기획` | `기획/` | 기획서, 기획 요약 v1·v2, 취합본, 재사용 검토 |
| `조사` | `조사/` | 대구 역사 관광 사례 조사 |

### 작업 방법
- 해당 주제 브랜치로 옮겨 작업합니다: `git checkout 기획`
- 올릴 때: `git push origin 기획`
- 공통 규칙(CLAUDE.md, README)은 `main`에서만 고칩니다.
