# TREAGENT

팀 TREAGENT의 작업 저장소입니다.

## 현재 프로젝트

**대구 하늘열차 이야기 산책 (기획 단계)**
- 대구 도시철도 3호선을 무대로 한 선택형 이야기 산책 프로그램
- 걸은 길이 한 권의 이야기 책으로 남는 구조

## 팀

- 박민지
- 2명 추가 모집 중 (확정 전)

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `기획/` | 기획서, 기획 요약, 취합본, 재사용 검토 |
| `자료/` | 조사 결과, 사례 분석, 외부 참고 자료(원본 PDF 등) |
| `디자인/` | 고객 여정 지도 HTML |
| `발표/` | 발표 자료, 대본, 시연 영상 |
| `brand/` | 페르소나, 캐릭터 콘셉트, 한 장 기획서 |
| `storyboard/` | 훅 후보, 스토리 구조 |
| `.claude/skills/` | 브랜드 스킬 (세계관, SKILL.md) |

## 작업 방법

- `main`에서 바로 작업하고 커밋·푸시합니다.
- 큰 변경은 작업 브랜치를 만든 뒤 `main`으로 합칩니다.
- 공통 규칙(CLAUDE.md, README)은 `main`에서 고칩니다.

## 작업 규칙

자세한 규칙은 [CLAUDE.md](CLAUDE.md)를 따릅니다.
- 확인되지 않은 사실은 `[미검증]`으로 표시합니다.
- 출처는 실제로 확인한 주소만 인용합니다.
- 공개 전 개인정보와 위치 정보를 점검합니다.
