# TREGENT

- 용도: 대구 수달 마스코트 도달쑤로 대구의 골목·시장·맛을 알리는 캐릭터 콘텐츠 팀 프로젝트 저장소
- `main`: 발표 최종 파일(`1104발표/`), 참고 자료(`references/`), 공통 규칙
- 팀원 브랜치
  - `심소형`: `reports/`(보고서), `research_notes/`(보고서별 조사 노트), `files/`(PPT 등 작업 파일), `AI_FLOW/`(AI FLOW로 만든 `이미지/`·`영상/`)
  - `박민지`: `agent/`(그림 에이전트 코드), 캐릭터 이미지
  - `허채연`: 발표 작업 파일
- 파일명 규칙: 보고서와 노트 폴더는 같은 한글 제목을 사용 (예: `reports/대구 캐릭터 콘텐츠 기획 보고서.md`), AI FLOW 결과물은 내보낸 영문 이름을 유지
- 참고 자료 출처: `references/도달쑤 캐릭터 가이드 매뉴얼(리뉴얼 전).pdf`는 대구광역시 공개 파일(2025 도시브랜드 숏폼 공모전 자료실)을 PDF로 변환한 것으로 공공누리 제2유형(출처표시+상업적 이용금지) 조건을 따름. 리뉴얼 이전 디자인이고, 일러스트 파일에서 복원해 일부 표정이 빠지거나 겹쳐 보일 수 있음
- 작업 규칙: [CLAUDE.md](CLAUDE.md)
