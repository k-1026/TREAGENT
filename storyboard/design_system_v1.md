## 2. 글자

- 글꼴: `Malgun Gothic`, `Apple SD Gothic Neo`, `Noto Sans KR`
- 제목(화면) 22~24px / 800, 머리말 13px / 700
- 본문 14px, 설명 11~13px (보조 글자는 `--muted`)
- 주요 버튼 16px / 800, 보조 버튼도 16px / 800 (같은 크기, 아래 3절)
- 글자는 잘리지 않아야 합니다. 머리글은 한 줄, 길면 글자 크기를 18px로 줄입니다 (쉼터 제목 사례, 확인: 측정 scrollWidth = clientWidth)

## 3. 버튼

- 주요 행동 `.cta`: 빨강 바탕(`#d03a2f`), 흰 글씨, 높이 52px 통일 (2026-11-20). 홈 첫 화면의 큰 행동 버튼만 68px 예외 `[확인 필요]`, 가로 100%
- 보조 행동 `.row px`: 크림/종이색 바탕, `--ink` 글씨, 같은 높이
- 한 줄에 두 버튼이 있으면 같은 높이, 같은 글자 크기, 같은 여백 (브리핑: 왼쪽 주요 "확인", 오른쪽 보조 "이전으로")
- 뒤로 가기: 머리글 왼쪽 "‹ 이름" 버튼 + 본문 아래 보조 버튼 1개 (화면마다 돌아갈 곳을 둠)

## 4. 테두리와 면

- 픽셀 테두리 `.px`: 위·아래·좌·우 3px `--ink` 그림자 + 아래 6px `--shade` 면
- 말풍선: 종이색 바탕, 2px `--ink` 테두리, 아래 꼬리 (검은 삼각형 + 종이색 삼각형)
- 구분선: 한 칸 안의 구역은 2px `--ink` 선으로 나눔 (브리핑 설명 칸)
- 모든 테두리 굵기는 같아야 합니다 (화살표 사례: 대각선 꼭짓점까지 같은 굵기 stroke 사용)

## 5. 태그 (chip)

## 10. 화면 구성 규칙

- 같은 목적의 버튼은 같은 자리에 둠 (주요 행동은 화면 아래쪽, 뒤로 가기는 머리글)

- 자동 전환 없음. 화면은 클릭으로만 바뀜 (발표용 `?lock` 모드)
- 게임 요소 최소화 (프로젝트 방향)

## 16. 앱 이식 절차 (dev 기준, 팀 세팅 가이드 반영)

- 기준 문서: `dev/team_setup_guide_v1.md` (세팅), `dev/README.md` (환경변수와 막혔을 때)
- 작업 브랜치: 최신 `origin/dev`에서 따고, PR은 `dev`로 엽니다. 이식 대상은 `dev/app/`입니다.
- 서버: 화면 작업은 Railway 서버를 그대로 씁니다. 서버 코드는 건드리지 않습니다.
- 환경: Node 22 이상, `npx expo install`로 패키지 설치, `npx expo start -c`로 실행. Node 팀 기준 버전은 가이드 "결정 필요"입니다.
- 패키지 추가 금지 (기본): 움직임은 React Native 내장 `Animated`로 만듭니다. 꼭 추가해야 하면 `package.json`과 `package-lock.json`을 같은 PR에 함께 올립니다. 현재 앱에는 `react-native-reanimated`가 없습니다.
- 웹에서 화면 확인 (로컬 서버 필요):
  1. `dev/server/.env`에 `CORS_ORIGIN=http://localhost:8081`을 적고 서버를 실행합니다 (`npm start`).
  2. `dev/app/.env`의 `EXPO_PUBLIC_SERVER_URL`을 `http://localhost:3000`으로 바꿉니다. 확인 뒤 Railway 주소로 되돌립니다.
  3. `dev/app`에서 `npx expo start -c --web`을 실행합니다.
  - 배포된 서버는 `treagent-web.vercel.app`만 허용하므로 로컬 주소에서는 CORS로 막힙니다.
- 비밀 값: `.env`와 키는 문서, PR, 스크린샷에 넣지 않습니다.
- 반영 순서: 작업 PR → `dev` 병합(팀원 1명 승인) → `dev → main` 승격 PR (병합 방식 `Create a merge commit`) → `main` 병합 후 Vercel 자동 배포. 승격 workflow는 매일 18:00에 올립니다 (`CLAUDE.md` 저장소 작업 규칙).
- 검증 체크리스트 (13절)에 더해 확인할 것: 로컬 서버로 로그인과 홈 데이터가 뜨는지, 웹과 폰(Expo Go)에서 같은 화면인지.
