## 2. 배치 (세로 9:16, 창작, 2026-11-17 수정)

```
┌─────────────────────────┐
│ 상태 영역 56px             │
│ [날씨 배지 ▾] 구·군·기준 시각  │  ← 장면 위 좌상단, 탭하면 지역 변경
│ ┌─────────────────────┐ │
│ │ 도트 방 장면 (3:2 그림)  │ │  ← 높이 316 (상태 영역 56 + 그림 260)
│ │ 말풍선 / 하랑이 (앱에서 얹음)│ │
│ │ [배너: 특보·경로 변경]    │ │  ← 해당 상태에만, 장면 아래쪽에 겹침
│ └─────────────────────┘ │
│ [주 버튼 슬롯] 고정 높이     │  ← 상태에 따라 내용만 바뀜
│ [코스 전체|오늘의 길][쉼터][지난 여행] │  ← 퀵 버튼 3개 고정
│ 오늘의 추천 길 (세로 카드 1~3개) │  ← 옆으로 밀지 않음
│ (자리가 남으면 도장 미리보기)   │
│ ─────────────────────── │
│   홈   ·   장부   ·  내 정보  │
└─────────────────────────┘
```

- **상태가 바뀌어도 주 버튼과 추천 길의 위치는 같습니다.** 이어하기 카드를 따로 쌓으면 아래가 전부 밀려 내려오기 때문입니다.
  - 주 버튼 슬롯: 진행 없음 = 오늘의 길 확인, 진행 있음 = 이어하기, 폭염·호우·날씨 확인 불가 = 가까운 쉼터 보기.
  - 진행 중에는 퀵 버튼 첫 칸이 "오늘의 길"이 됩니다. 진행 중 새 여행 허용 여부는 `[결정 D-08]`.
- **추천 길은 세로로 쌓고 옆으로 밀지 않습니다.** P0에서는 규칙 엔진이 모드를 정하고 검수된 DB에서 경로를 고르며(AI가 코스를 만들지 않음), 하루 추천 길은 1~3개 `[예시]`라 밀어서 볼 만큼 많지 않습니다 (plan/spec/treagent_tech_spec_v1.md:484, brand/game_concept.md:35). 전체 코스는 "코스 전체"에서 봅니다.
- 하단 탭 장부(S-09), 내 정보(S-10) 화면도 목업에서 눌러 볼 수 있습니다.


- 장면 영역: 폭 390 x 높이 316 (상태 영역 56 + 그림 260, 3:2 그림을 폭에 맞춤). 논리 화면 390 x 844 기준 `[확인 필요: 실제 기기 폭과 안전 영역]`. 배지와 말풍선이 겹치지 않게 배지는 좌상단, 말풍선은 문과 창 사이 벽에 둡니다.
- 앱이 얹는 것: 날씨 배지, 하랑이 스프라이트, 말풍선. 그래서 그림에는 하랑이를 넣지 않고 자리를 비웁니다.
  - 왜 굳이: 표정·대사에 따라 하랑이를 바꿔 끼우려면 배경과 분리돼 있어야 합니다.
  - 없으면 깨지는 것: 배경 이미지를 표정 수만큼 다시 만들어야 합니다.
- 장면 안 자리: 왼쪽 위 비움(날씨 배지), 가운데 아래 바닥 비움(하랑이), 하랑이 머리 위 비움(말풍선).

## 3. 요소 목록

**필수**
1. 날씨 배지: 기온, 체감, 기준 시각. AWS 여부는 탭하면 보이는 상세에 둡니다 `[확인 필요]` (CLAUDE.md 폭염·한파 안전 정보 기준).
2. 도트 하랑이와 말풍선: 호칭은 이름이고, 없으면 "길동무". 대사는 `[승인 대사 대기]`.
3. 이어하기 카드: 진행 여행이 있을 때만. 다음 장소 이름을 보여 줍니다.
4. 오늘의 길 확인 버튼: S-14로 갑니다.
5. 코스 카드: 이름, 소요 시간, 실내·야외 아이콘 (D-04 첫 코스에 따라 내용 변경).
6. 하단 탭 3개와 장부 진입.
7. 쉼터 바로가기(C): 폭염·호우 상태에서 주 버튼 자리를 대신합니다. 안전 안내를 먼저 보이게 하려는 것입니다 (plan/spec/treagent_tech_spec_v1.md:510, 512).
8. 오늘의 빈 칸 한 줄(A): 조건이 장부의 빈 칸과 맞을 때만 말풍선에 나옵니다 (brand/worldview.md 4-3절). 칸을 채우라는 독촉 문구는 쓰지 않습니다 (5-3절).

**선택**
- 장부 미리보기(B): 최근 받은 능금 스탬프(brand/character/images/stamp_nungeum.webp) 2~3개. 자리가 남을 때만 넣습니다. 아직 못 받은 자리는 흐리게 보여 줍니다.

**쓰지 않음**: 호감도 수치·게이지, 포인트·재화, 랭킹, 칸 채우기 독촉 문구, 정령·도사 수 언급 (worldview.md 2-1절, 3-3절, 4-10절).

## 4. 상태 (목업의 상태 선택 7종)

| 상태 | 장면·배지 | 주 버튼 | 추천 길 영역 |
|---|---|---|---|
| 진행 여행 없음 | 인사, 맑음 배지 | 오늘의 길 확인 | 카드 1~3개 |
| 진행 여행 있음 | 출발 준비 | 이어하기 | 카드 (새 여행 허용은 D-08 결정 전) |
| 진행 여행 + 경로 변경 알림 | 장면 아래 배너 "경로가 바뀌었어요" | 이어하기 | 카드 (F-21 알림 후 S-07) |
| 폭염 | 배지 빨강, 야외 중단 배너 | 가까운 쉼터 보기 | 실내·열차 위주만 |
| 호우·이동 보류 | 신규 이동 보류 배너 | 가까운 쉼터 보기 | 카드 없음, 안내 문구 |
| 날씨 확인 불가 | 배지 회색 "불러오지 못했어요" | 가까운 쉼터 보기 | 카드 없음. AI 추측 없이 쉼터만 (명세 496) |
| 코스 없음 | 갸웃 | 오늘의 길 확인 | 빈 상태 문구 |

- 앱에 다시 들어왔을 때는 낮잠에서 깨는 연출을 씁니다 (brand/character/harangi_character.md 예문 17).
- 표정과 대사는 승인 전이라 자리만 둡니다 `[승인 대사 대기]`.

## 5. 외출 전환 (코스를 선택하면)

- 흐름: 코스 카드 탭 → 하랑이가 문 쪽으로 걷고 문이 열려 골목이 보임 (약 1.5초, 건너뛰기 가능) → S-04 코스 상세.
- 여행이 진행 상태가 되는 시점은 S-04에서 "길 확인"을 누를 때입니다 (storyboard/app_screen_storyboard_v1.md S-04, S-05). 카드를 눌렀다고 바로 여행이 시작되지는 않습니다 `[결정 필요]`.
  - 후보 1 (제안): 위 흐름대로 연출만 시작, 여행 시작은 S-04에서.
  - 후보 2: 연출을 "길 확인" 순간으로 옮김. 이용자가 정보를 보고 정한 뒤 나서므로 결정이 앞서지 않습니다. 대신 코스 선택의 즉시성은 약해집니다.
- 필요한 그림: 문 닫힌 방 / 문 열림 / 문 밖 골목. 하랑이 걷는 스프라이트 `[확인 필요: 기존 파일에 있는지]`.
- 모션 줄이기 설정에서는 연출 없이 바로 전환합니다.

## 6. 배경 변형 (날씨와 시간대)

- 방, 가구, 구도는 고정하고 **창 밖, 하늘, 빛의 색, 바닥 빛무늬, 작은 소품**만 바꿉니다.
  - 왜 굳이: 변형마다 방이 달라지면 같은 곳이라는 느낌이 깨집니다. GPT에 기본본을 첨부해 "이 방은 그대로, 창 밖만 바꿔"로 만듭니다.
- 날씨는 모드 시나리오 5가지를 따릅니다 (plan/spec/treagent_tech_spec_v1.md:506-512). 모드표 통합은 `[결정 D-06]` 이후 맞춥니다.

| 날씨 시나리오 | 장면 변화 (창작) |
|---|---|
| 평상시·야외 (기본) | 맑은 하늘, 바닥에 창 모양 햇빛 |
| 더운 날·그늘 | 강한 햇빛, 창에 발 반쯤, 선풍기 |
| 폭염·실내 | 하늘이 뿌옇고 더 밝음, 커튼 닫힘, 선풍기 켜짐, 물 컵 |
| 약한 비 | 회청색 하늘, 창에 빗방울, 우산꽂이 |
| 호우·이동 보류 | 짙은 구름과 굵은 비, 방 안은 아늑한 등불. 번개와 공포 연출은 쓰지 않음 (CLAUDE.md) |

- 시간대: 아침, 낮(기본), 저녁, 밤 (창작 후보 2개: 3구분 아침·낮·저녁밤 / 4구분). 경계 시각은 `[결정 필요]`.
- 만드는 순서: ① 평상시·낮 ② 날씨 4종(낮) ③ 시간대 3종(맑음). 조합 전부(5 x 4)는 만들지 않고, 필요한 조합만 나중에 추가합니다 `[결정 필요]`.
