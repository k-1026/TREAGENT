최소 글자 크기 수정 시안 v1 (3번)

목업의 10px 글자는 이미 11px로 올렸습니다. 남은 것은 9px 글자 4곳입니다. 기준은 디자인 기준 문서 15절의 "최소 11px"입니다. 아래는 수정 전과 수정 후 모습, 고칠 위치, 확인 방법입니다.

1. 9px이 쓰인 곳 4곳

위치 (목업 파일 줄)무엇인가현재수정
.card .th (97행)코스 썸네일 자리의 안내 글자9px11px
.reg .tag (139행)권역 "완주 배지" 태그9px11px
.thumb (148행)앨범·내 여행 썸네일 자리 글자9px11px
.spot em (171행)지도 장소 이름표9px11px (이름이 길어 지도 칸이 넓어질 수 있음)

글자가 너무 작아 읽기 어렵습니다. 발표 화면에서는 거의 보이지 않습니다.

3. 고치는 방법 (CSS 한 줄씩)

각 규칙에서 font-size:9px를 font-size:11px로 바꿉니다. 다른 속성은 건드리지 않습니다.

97행 · .card .th
font-size:9px → font-size:11px

썸네일 자리 한 칸(58px)에 글자가 들어가므로, 줄바꿈 후 높이가 넘치는지 확인합니다.

139행 · .reg .tag
font-size:9px → font-size:11px

태그는 세로 여백이 좁습니다. 높이가 커지면 패딩 0을 유지합니다.

148행 · .thumb
font-size:9px → font-size:11px

64 x 48 자리 안에 글자가 두 줄로 들어갑니다. 줄 수를 확인합니다.

171행 · .spot em
font-size:9px → font-size:11px

장소 이름이 길면 지도에서 서로 겹칠 수 있습니다. 긴 이름은 줄여서 쓰거나 위치를 조정합니다.

4. 확인 방법

수정 후 아래 명령으로 9px과 10px이 없는지 확인합니다.

grep -n "font-size:9px\|font-size:10px" storyboard/app_home_mockup_v1.html

결과가 없으면 통과입니다. 목업 화면에서 긴 글자가 잘리는지는 브라우저로 한 번 더 봅니다 (특히 지도 장소 이름과 썸네일).
