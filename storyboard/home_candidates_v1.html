홈 빈 자리 후보 비교 v1

최근 한 장을 뺀 뒤 홈 화면에 남는 빈 자리를 채울 후보입니다. 각 후보는 같은 홈 화면에서 아래 칸에 들어가는 모습으로 보여 줍니다. 아래 표에서 필요한 데이터와 준비 상태를 확인하고 하나를 고르면 됩니다. 그림은 자리 표시입니다.

A. 날씨 요약 카드

오늘 날씨와 기준 시각, 추천 길 한 줄을 보여 줍니다. 날씨에 따라 내용이 바뀝니다.

준비: 목업 있음

진행 중인 여행이 있을 때만 나타나는 카드입니다. 없으면 빈 자리로 남습니다.

장점: 실제로 가장 많이 쓸 기능. 진행 중인 사람에게 바로 도움이 됨.
단점: 진행 중이 아닐 때는 빈 자리가 그대로 남음 (다른 후보와 함께 써야 함).
필요 데이터: 진행 여행 상태 (다음 장소, 방문 수) — 앱 상태 관리 필요
준비: 목업 있음 (상태 드롭다운 '진행 여행 있음'), 서버 연결 없음

C. 쉼터 카드

폭염·호우일 때 쉼터 안내를 크게, 평소에는 작게 보여 줍니다.

단점: 평소에는 쓸 일이 적어 빈 자리가 여전히 많음.
필요 데이터: 쉼터 목록, 운영 시간, AWS 여부 — 서버 응답에 "쉼터 목록"이 있음
준비: 목업 있음 (쉼터 화면 연결), 실제 데이터 없음
