- 기준일: 2026-11-16
- 목적: 소정(FE)은 화면 구성을, 민지·소형(DES)은 Figma 화면을 이 문서 기준으로 시작합니다.
- 근거: 발표 자료 2026-11-13 `presentation/20261113/20261112_plan_pitch_v10.html` 9번 슬라이드(유저 플로우), 기능·기술 명세 `plan/spec/treagent_tech_spec_v1.md` 5장(화면 목록 S-01~S-14).
- 표기: `[분기 D-xx]` 결정 후 확정, `[승인 대사 대기]` 대사 세트(명세 7-3) 완료 후 채움, `[확인 필요]` 추가 확인.

## 1. 흐름 한눈에 보기 (발표 슬라이드 9번 기준)

```
시작 앱 실행
  ├─ 세션 없음 → S-01 로그인·가입
  │                 └─ 처음 방문 → S-02 첫 만남 → S-03 홈
  └─ 세션 있음 → S-03 홈
                  ├─ 오늘의 길 확인 → S-14 주변 추천 또는 S-04 코스 상세
                  │                       └─ 길 확인 → 이동 → S-05 여행 지도·진행
                  │                                          ├─ 조건 변경 → S-07 경로 변경·보류 → (대체 길 제안 / 계속)
                  │                                          └─ 목적지 도착 → S-06 장소 상세·방문 확인
                  │                                                              ├─ 실패 → 재시도 (S-06 내)
                  │                                                              └─ 성공 → 장부 자동 기록 → 다음 장소 또는
                  │                                                                        S-08 완주·내 여행 한 장
                  └─ 장부 보기 → S-09 장부·주머니 / 내 계정 → S-10

운영자: S-11 운영자 로그인·장소 목록 → S-12 장소 상태 변경 / S-13 경로·대사 검수·게시
```

## 2. 화면별 스토리보드

### S-01 로그인·가입
- 진입: 앱 실행 (세션 없음)
- 행동: 로그인 또는 가입 선택 → 입력 → 제출
- 다음: 처음이면 S-02, 아니면 S-03
- 상태: 입력 오류, 로그인 실패, 세션 만료 (명세 5장)
- 하랑이: 차분한 표정, 안내 한 줄 `[승인 대사 대기]`
- 분기: `[분기 D-01]` 로그인 방식 (A 이메일·비밀번호 / B 소셜 1종). 방식에 따라 입력 칸 구성이 달라집니다.
- 데이터: 인증 (BE)

### S-02 첫 만남
- 진입: S-01 직후 (처음 방문)
- 행동: 하랑이 소개 → 닉네임 입력 또는 건너뛰기("길동무" 기본 호칭)
- 다음: S-03 홈
- 상태: 닉네임 건너뛰기
- 하랑이: 인사 일러스트와 대사 `[승인 대사 대기]`
- 데이터: 프로필 저장

### S-03 홈
- 진입: S-01·S-02 이후, 또는 앱 실행 (세션 있음)
- 행동: 진행 중인 여행 이어하기, 오늘의 길 확인, 코스 보기, 장부 보기
- 다음: S-04, S-14, S-05, S-09
- 상태: 진행 여행 없음 / 있음, 코스 없음
- 하랑이: 대사 자리 `[승인 대사 대기]`
- 분기: `[분기 D-04]` 첫 코스 (A 코스 A 중구 30분 / B 파일럿 생활권)에 따라 코스 썸네일 내용이 달라짐
- 데이터: 프로필, 진행 여행, 코스 목록

### S-14 주변 추천 (위치·날씨)
- 진입: S-03의 "오늘의 길 확인" 또는 앱 첫 실행 시 위치 요청
- 행동: 위치 권한 허용 → 현재 위치 기준 추천 / 거부 → 구·군 선택 → 날씨와 모드에 맞는 장소 목록
- 다음: S-04 (추천 장소 선택)
- 상태: 위치 권한 요청, 거부 시 구·군 선택, 이동 보류(날씨·특보로 야외 중단), 추천 없음, 날씨 확인 불가
- 하랑이: 놀람 또는 차분 표정. 이동 보류 시 쉼터 안내 `[승인 대사 대기]`
- 분기: `[분기 D-06]` 모드 기준 (체감온도·특보 수치). 모드별 아이콘(실내·그늘·야외·전시)을 이 기준에 맞춥니다.
- 데이터: 추천 API, 구·군 목록, 기준 시각

### S-04 코스 상세·오늘의 길
- 진입: S-03, S-14
- 행동: 코스 정보 확인 → 오늘의 길(경로) 확인 → "길 확인" 선택 → 이동 시작
- 다음: S-05
- 상태: 경로 확인 중, 확인 불가(날씨·운영 상태), 쉼터 안내
- 표시: 기준 시각과 추천 사유 (명세 F-05)
- 하랑이: 길 안내 대사 `[승인 대사 대기]`
- 에셋: 장소 사진, 실내·야외 아이콘
- 데이터: 코스, 경로 추천, 기준 시각

### S-05 여행 지도·진행
- 진입: S-04에서 이동 시작, 또는 S-03 "진행 중 여행"
- 행동: 다음 장소 확인 → 외부 지도 앱으로 길찾기 → 진행률 확인
- 다음: 조건이 바뀌면 S-07, 도착하면 S-06
- 상태: 외부 지도 열기 실패
- 에셋: 진행률 바, 스탬프 슬롯
- 데이터: 여행, 방문 목록, 운영 상태

### S-07 경로 변경·보류
- 진입: S-05에서 날씨·특보·운영 상태가 바뀌었을 때
- 행동: 변경 사유 확인 → 대체 길 수락 / 보류 / 계속
- 다음: 수락하면 S-05, 보류하면 S-05 (보류 상태 표시), 대체 길이 없으면 쉼터 안내
- 상태: 대체 길 있음 / 없음
- 하랑이: 놀람(변경 알림), 차분(보류) 표정 `[승인 대사 대기]`
- 에셋: 쉼터 아이콘
- 데이터: 재평가 API, 쉼터 정보

### S-06 장소 상세·방문 확인
- 진입: S-05에서 목적지 도착
- 행동: 인증 지점 설명과 사진 확인 → 위치 권한 → 방문 확인 (GPS) → 결과
- 다음: 성공 → 장부 기록 후 다음 장소 또는 S-08 / 실패 → 같은 화면에서 재시도
- 상태: 권한 거부, 측위 실패, 거리·정확도 문제, 응답 누락
- 하랑이: 표정 변화(성공·실패·재시도)에 따른 대사 `[승인 대사 대기]`
- 분기: `[분기 D-05]` 인증 방식과 GPS 반경 (A GPS만 / B GPS+현장 단서). B라면 단서 입력 화면이 추가됩니다.
- 에셋: 인증 지점 사진·설명
- 데이터: 장소, 인증 지점 설명, 방문 API

### S-08 완주·내 여행 한 장
- 진입: 마지막 장소 방문 성공 후 자동
- 행동: 완주 확인 → 한 장 카드 보기 (날짜, 스팟, 날씨) → 저장 또는 닫기
- 다음: S-09 장부
- 상태: 없음 (명세 5장)
- 에셋: 능금 도장, 한 장 카드 템플릿
- 데이터: 방문 기록, 완주 판정

### S-09 장부·주머니
- 진입: S-03, S-08
- 행동: 지난 여행 기록 보기, 수집 스탬프 보기
- 다음: S-08 (여행 카드 다시 보기)
- 상태: 기록 없음 (빈 상태 일러스트)
- 에셋: 스탬프 이미지, 빈 상태 일러스트
- 데이터: 여행 목록, 스탬프 목록

### S-10 내 계정
- 진입: S-03 메뉴
- 행동: 닉네임 확인·수정, 로그아웃
- 다음: 로그아웃 시 S-01
- 데이터: 프로필

### S-11 운영자 로그인·장소 목록
- 진입: 운영자 웹 접속
- 행동: 운영자 로그인 → 장소 목록 확인
- 다음: S-12, S-13
- 상태: 권한 없음
- 분기: `[분기 D-03]` 운영자 웹 형태 (A Expo web 재사용, 상태 변경만 / B 별도 웹, 코스·대사 편집 포함)
- 데이터: 운영자 인증, 장소 목록

### S-12 운영자 장소 상태 변경
- 진입: S-11
- 행동: 장소 선택 → 운영 중단 또는 재개 → 저장
- 다음: 저장 후 앱에 반영 (대체 길 안내 확인이 시연 기준)
- 상태: 저장 실패
- 데이터: 상태 변경 API

### S-13 운영자 경로·대사 검수·게시
- 진입: S-11
- 행동: 경로 또는 대사 초안 검수 → 승인 또는 반려 (반려 사유 입력) → 게시
- 다음: 게시 후 앱 반영
- 상태: 반려 사유
- 분기: `[분기 D-03]` 편집 범위 (B일 때만 코스·대사 편집 포함)
- 데이터: 검수 API

### S-15 미션 안내 (도착 후, 미션이 있는 장소)
- 진입: S-06 도착 확인(GPS) 성공 후 미션이 있는 장소
- 행동: 미션 종류 확인 (영수증형 또는 퀴즈형) → 내용 보기 → 시작 또는 나중에 하기
- 다음: 식당·카페는 S-16, 박물관·공원은 S-17. 나중에 하기는 S-05로 돌아가고, 여행 지도에 "미션 대기" 표시
- 버튼: [미션 내용 보기] [미션 시작] [나중에 하기]
- 상태: 미션 대기
- 데이터: 장소의 미션 종류와 설명 (장소 DB)

### S-16 영수증 인증 (식당·카페)
- 진입: S-15에서 미션 시작
- 행동: [영수증 찍기] → 자동 검증 (상호명, 날짜 확인) → 성공 시 S-18
- 가이드: "카드 번호와 금액은 가려 주세요." (화면에 상시 표시)
- 상태: 검증 중(로딩), 상호명 불일치, 날짜 불일치, 글자 인식 실패, 재촬영 필요
- 영수증이 없을 때: [영수증 없이 하기] → 현장 사진 또는 퀴즈 (`[분기 M-02]`)
- 실패 3회: 쉬운 퀴즈(S-17)로 바꿈 (`[분기 M-03]`)
- 개인 정보: 사진은 저장하지 않고, 검증이 끝나면 바로 지움. 결과(통과 여부)만 남김 `[확인 필요: 처리 방식]`
- 데이터: 장소의 상호명, 검증 결과

### S-17 퀴즈 (박물관·공원, 또는 대체·쉬움)
- 진입: S-15에서 퀴즈 선택, S-16에서 영수증 없이 하기, 또는 영수증 실패 3회 후
- 행동: 문제 읽기 → 보기 선택 → 정답 확인 → 다음 문제 → 모두 맞히면 S-18
- 버튼: [정답 고르기] [힌트 보기] [다시 풀기]
- 오답: 힌트를 보여 주고 다시 풀게 함. 벌점이나 실패 처리 없음
- 난이도: 기본 (장소 문제), 쉬움 (영수증 실패 3회 후)
- 상태: 오답, 힌트 사용, 모두 완료
- 데이터: 장소별 문제 2~3개, 보기 3~4개 (출처 있는 사실 확인표에서만 만듦)

### S-18 미션 완료
- 진입: 영수증 검증 성공 또는 퀴즈 완료
- 행동: 도장 찍히는 연출 → [도장 확인] → 오늘의 길 일기 반영 → 다음 장소 (S-05)
- 상태: 없음
- 데이터: 방문 기록, 일기 반영 (S-08)

## 3. 공통 요건

- 모든 화면에 오류, 로딩, 빈 상태를 포함합니다 (명세 5장).
- 하랑이 말풍선 컴포넌트를 1개 만들어 모든 화면에서 재사용합니다.
- 대사 문구는 승인 대사 세트가 완성되기 전까지 `[승인 대사 대기]`로 둡니다.
- 금칙어(유일, 최초, 최고)는 대사와 화면 문구에 쓰지 않습니다.
