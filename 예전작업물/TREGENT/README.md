# TREGENT

- 용도: 대구 수달 마스코트 도달쑤로 대구의 골목·시장·맛을 알리는 캐릭터 콘텐츠 팀 프로젝트 저장소
- 핵심 메시지: "도달쑤 따라가면 골목마다 먹을 게 있다" (제안 단계)
- 팀 자산
  - 기획: 「도달쑤 일일 알바」 콘텐츠 기획과 인물 설정(통합 보고서, 제안 단계)
  - 기술: 관광지·포즈·소품을 합성하는 그림 에이전트(`박민지` 브랜치)
  - 자료: 지역 캐릭터 성공·실패 조사, 대구 골목·시장 자료, 알바 면접·코스 설계안
  - 샘플: AI FLOW 이미지·영상
  - 주의: 도달쑤 캐릭터 자체는 대구시 자산이며, 시 페이지의 이용 조건은 공공누리 제2유형(상업적 이용금지)
- `main`: 발표 최종 파일(`1104발표/`)과 공통 규칙
- 팀원 브랜치
