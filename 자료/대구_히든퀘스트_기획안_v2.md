## 0. 왜 해야 하는가: 유치 근거

### 0-1. 문제 (대구 관광의 구조적 약점)
- 대구·경북 관광은 가을 축제와 일부 관광지에 의존하는 구조라는 지적이 있습니다 `[검증됨: 2026 보도]`.
- 방문객은 늘었지만 체류 시간은 줄고 있다는 보도가 있습니다 `[검증됨: 2026 보도]`.
- 여름에는 도심 체감온도가 높습니다. 2026년 7월 현장 취재에서 수성구 범어네거리는 기온 36℃, 체감 40℃로 측정됐습니다 `[검증됨: 영남일보]`.
- 결과적으로 **여름과 겨울에 나갈 이유가 부족합니다.** 이 서비스는 그 틈을 메웁니다.

### 0-2. 가치 제안
| 대상 | 얻는 것 |
|---|---|
| 방문객 | 날씨와 상관없이 할 일이 있음. 실내와 그늘이 콘텐츠가 됨 |
| 2030 이용자 | "오늘은 너무 더워서 못 나가겠다"를 "오늘은 실내 퀘스트 날"로 바꿈 |
| 대구시·구청 | 비수기 방문 분산, 쉼터와 실내 시설 활용도 향상, 안전 메시지 전달 |
| 지역 상권 | 실내 경로에 있는 카페·식당·박물관 방문 유도 (보조 효과) |

### 0-3. 유치 채널 (사람을 끌어들이는 방법)
1. **날씨 알림 연동**: 폭염·한파 알림과 함께 "오늘의 퀘스트"를 보냅니다. 예: "오늘 체감 38℃. 실내 퀘스트 3개가 열렸습니다."
2. **SNS 챌린지**: 시즌 해시태그 인증 (#대프리카생존, #팔공히든퀘스트 등). 비짓대구의 공식 SNS와 협업을 제안합니다. 비짓대구는 2026년 SNS 대상 관광 부문 대상을 받은 바 있습니다 `[검증됨]`.
3. **숙박 연계**: 1박 2일 체크인 고객에게 첫 퀘스트 무료 이용권을 줍니다 `[확인 필요: 숙박업계 제휴]`.
4. **대학 캠퍼스**: 대구 소재 대학의 신입생 오리엔테이션이나 학생 행사에 연계합니다 `[확인 필요]`.
5. **친구 초대 (팀 모드)**: 2~4명이 같은 단서를 나눠 찾습니다. 2030의 모임 문화에 맞춥니다.
6. **시즌 한정 배지**: 시즌마다 한정 배지를 주어 수집욕을 자극합니다.
7. **지자체 캠페인 연계**: 폭염·한파 안전 캠페인과 메시지를 함께 씁니다. "안전하게 즐기는 대구"로 묶으면 행정 협업이 쉬워집니다 `[추정]`.

### 0-4. 성과 지표
- 비수기(7~8월, 12~2월) 방문 건수와 체류 시간
- 실내 퀘스트 완료율
- 쉼터 방문 기록 (안전 지표)
- 2주 내 재방문율
- 시즌 해시태그 게시물 수

## 3. 대구 특색 코스 후보 (억지 없이 고르는 기준)

### 3-1. 선정 기준
1. **대구 테스트**: "이 코스를 다른 도시로 옮기면 의미가 사라지는가?" → 예여야 합니다.
2. **날씨 적합성**: 계절별로 야외·실내 비율을 맞출 수 있는가?
3. **이동 효율**: 걸음을 줄일 수 있는가? (3호선 등 대중교통 활용)
4. **시간 완결성**: 30·60·90분 중 하나에 맞는가?
5. **안전 보장**: 쉼터, 화장실, 대체 경로가 있는가?

### 3-3. 억지로 넣지 않을 것
- 사과, 막창, 따로국밥 같은 음식은 **식사 장소로만** 씁니다. 음식이 코스 주제가 되면 억지스럽습니다.
- 대구 야구장은 구단 IP 제약이 있어서 **응원 날 보조 퀘스트**로만 씁니다 `[확인 필요]`.
- 드라마 촬영지는 장면 재현이 아니라 **지역 이야기의 일부**로만 씁니다.

## 4. 코스 설계 방법

### 4-1. 기본 구조
```
허브 (출발: 동성로·반월당·동대구·서문 중 택 1)
  → 스테이션 4~6곳 (각 장소에서 단서·미션)
  → 실내 백업 경로 (날씨가 나쁠 때 즉시 전환)
  → 종점 (배지, 이야기 책 기록)
```

### 4-2. 설계 원칙
- **야외 구간은 연속 15분 이하** (여름·겨울 안전)
- **모든 스테이션에 실내 대체 장소 1곳 이상**
- **이동은 3호선 등 대중교통 우선**으로 걸음을 줄임
- **한 코스 30·60·90분 중 하나**에 맞춤
- **화장실과 쉼터가 최대 10분 거리 안에** 있도록 설계 `[확인 필요: 쉼터 최신 위치 데이터]`
- **장소 정보는 검수된 DB에서만** 가져옴. AI가 장소를 만들지 않음

### 4-3. 코스 설계 체크리스트
- [ ] "대구 아니면 안 되는가?" 테스트 통과
- [ ] 계절 모드에 맞는 야외·실내 비율
- [ ] 대체 경로 존재
- [ ] 쉼터·화장실 거리 기준 충족
- [ ] 예약 필요 장소는 사전 안내 (팔공산 흘림골·갓바위 등)
- [ ] 운영 시간과 휴무일 확인

## 5. 코스 구성 (기본 + 시즌 한정)

### 5-1. 상시 코스 (사계절 공통)

**코스 A. 사라진 대구의 비밀 레시피 (중구, 30분)**
- 스토리: 옛 약재와 음식 레시피가 골목에서 사라졌습니다.
- 흐름: 동성로 → 근대골목 → 약령시 박물관 → 서문시장 → 종점
- 날씨 대응: 폭염·한파 시 약령시 실내를 먼저 가고, 야외 구간을 줄입니다.

**코스 B. 3호선 탐험 (60분)**
- 스토리: 하늘을 달리는 열차에서 도시의 단서를 찾습니다.
- 흐름: 반월당 또는 동대구 → 3호선 탑승 미션 → 청라언덕역 또는 서문시장역 하차 미션 → 종점
- 날씨 대응: 이동 대부분을 열차로 하므로 폭염·한파에 강합니다.

### 5-2. 시즌 한정 코스

| 시즌 | 코스 이름 | 흐름 | 핵심 장치 |
|---|---|---|---|
| **봄** | 약령시 축제 퀘스트 | 약령시 축제 기간 한방 체험 미션 → 근대골목 | 축제 공지와 연동 (날짜 고정 X) |
| **초여름** | 치맥 퀘스트 `[확인 필요]` | 두류공원 축제 연계 미션 | 축제 공지와 연동 |
| **여름** | **대프리카 서바이벌** | 실내 중심: 약령시 박물관 → 3호선 → 수성못 그늘 → 쉼터 확인 | 안전 점수, 폭염 모드 |
| **가을** | **팔공 히든 퀘스트** | 팔공산 단풍 코스 (케이블카 또는 도보 구간 선택) → 동화사 또는 갓바위 (예약 필수) | 단풍 시즌 예약 안내 |
| **가을 저녁** | 앞산 해넘이 | 앞산 전망대 해넘이 → 야경 전환 미션 | 연중무휴 장소 |
| **겨울** | **빛의 히든 퀘스트** | 동성로 연말 행사 → 실내 카페 → 근대골목 야경 | 한파 모드, 실내 우선 |
| **겨울 야간** | 야시장 암호 해독 | 서문시장 → 근대골목 야경 | 실내 대체 장소 필수 |

### 5-3. 축제 연동 규칙
- 축제 날짜는 해마다 바뀌므로 **고정 날짜가 아니라 공지 연동**으로 운영합니다.
- 축제 기간에만 열리는 한정 배지와 미션을 만듭니다.
- 2026 기준 약령시 축제는 5월 7~10일이었습니다 `[검증됨]`. 2027년 일정은 주최 측 공지로 확인합니다.

## 6. 게임 루프와 계절 모드

### 6-1. 날씨 모드 (사계절 확장)

| 조건 | 모드 | 퀘스트 방식 |
|---|---|---|
| **28℃ 미만, 쾌적** | 탐험 모드 | 골목·산·공원 야외 미션, 최대 60분 |
| **28~33℃** | 그늘 모드 | 그늘 경로, 실내 구간 포함 |
| **33℃ 이상** | 실내 모드 | 쉼터, 박물관, 카페, 3호선 중심 |
| **폭염특보** | **안전 모드** | 게임 일시 중지. 쉼터 안내, 물 섭취 알림 |
| **한파 (체감 -10℃ 이하) `[확인 필요]`** | 실내 모드 | 실내 중심, 야외는 짧게. 빙판 주의 안내 |
| **한파특보** | **안전 모드** | 게임 일시 중지. 실내 쉼터 안내 |
| **단풍 시즌 (가을)** | 혼잡 분산 모드 | 인기 장소 시간대 분산, 예약 안내 |
| **야간** | 야행 모드 | 야경과 야시장 미션 |

> 기준 수치는 기상청과 보건 기준으로 확정합니다 `[확인 필요]`.
> 안전 규칙은 AI가 아니라 **규칙 엔진**이 담당합니다.

### 6-2. 게임 루프
```
위치 + 체감온도 + 계절 + 시간 + 취향 입력
  → 규칙 엔진이 모드 결정
  → 검수된 장소 DB에서 코스 생성
  → 단서 찾기 → 미션 (사진·퀴즈·현장 인증)
  → 날씨 변화 시 실내 대체 경로로 전환
  → 배지 + 이야기 책 기록
```

## 7. 게임 요소

- **시즌 브랜드**: 여름 "대프리카 서바이벌", 가을 "팔공 히든 퀘스트", 겨울 "빛의 히든 퀘스트"
- **배지**: 날씨 대응 행동에 배지 (예: "그늘 장인", "실내 탐험가")
- **시즌 한정 배지**: 축제 시즌 한정 배지로 재방문 유도
- **안전 점수**: 물 섭취, 쉼터 방문, 무리한 야외 시간 줄이기 등을 점수화. 야외 시간을 늘리도록 유도하지 않음
- **이야기 책**: 완료 기록을 개인 이야기 책으로 묶음 (기존 기획의 핵심 기능과 연결)
- **팀 모드**: 2~4명이 단서를 나눠 찾음

## 8. AI 에이전트 구조

| 단계 | 담당 | 역할 |
|---|---|---|
| 입력 | 사용자 | 위치, 시간, 계절, 취향 |
| 환경 판단 | **규칙 엔진** | 체감온도, 특보, 계절 확인 → 모드 결정 |
| 장소 선택 | 규칙 + 검수 DB | 모드와 계절에 맞는 장소만 필터링 |
| 퀘스트 생성 | AI (LLM) | 스토리 문장과 미션 문구 생성 (사전 검수된 템플릿 안에서) |
| 진행 관리 | 규칙 엔진 + AI | 날씨 변화 시 경로 수정, 혼잡 분산 |
| 기록 | 저장소 | 배지, 완료 기록, 이야기 책 |

**설계 원칙**
- 안전 규칙은 AI가 바꿀 수 없습니다.
- LLM은 **문장**만 만들고, 장소와 쉼터 정보는 검수된 DB에서만 가져옵니다.
- 위치 정보는 **앱 사용 중에만** 수집합니다.

## 9. 장점과 리스크

### 장점
- 사계절 사용 가능. 비수기 방문 분산이라는 명확한 목적
- 대구 날씨와 지형을 콘셉트로 씀 (분지 더위, 팔공산 단풍, 앞산 전망)
- 3호선과 실내 시설을 게임 무대로 씀
- 안전 중심 설계로 지자체 협업이 쉬움

### 리스크
- **계절 콘텐츠 제작량**: 사계절이면 콘텐츠가 4배 필요합니다. 상시 코스 2개와 시즌 코스 1~2개씩으로 시작해야 합니다.
- **축제 의존**: 축제 일정이 바뀌면 시즌 코스가 흔들립니다. 축제 공지 연동 규칙이 필요합니다.
- **쉼터 정보 정확도**: 대구 무더위쉼터 1,196곳 중 오후 6시 이후까지 운영하는 곳은 235곳(19.6%), 24시간은 5곳 (2026-08 기준, 매일신문) `[검증됨]`. 운영 시간 검증을 자주 해야 합니다.
- **안전 책임**: 폭염·한파 사고에 대한 면책과 법률 검토가 필요합니다.
- **위치 권한 부담**: 이탈 위험. 사용 중 수집 원칙을 명확히 알려야 합니다.
- **기존 서비스**: 부산 중구 스마트 관광전자지도는 위치 기반 자동 스탬프를 이미 제공합니다 `[검증됨]`. 차별점은 계절과 날씨에 따른 경로 변화와 생성형 스토리입니다.
- **가을·겨울 수요 근거**: 계절별 방문 통계를 찾지 못했습니다 `[확인 필요]`.

## 10. MVP 범위 (단계별)

### 1단계: 해커톤 MVP (여름 시즌으로 검증)
- 장소 DB 15~20곳 (중구 중심, 검수 완료)
- 규칙 엔진 (체감온도 + 폭염특보)
- 코스 A 1개 + 실내 대체 경로
- 퀘스트 문장 생성 (검수 템플릿 안에서)
- 사진 인증 1종, 퀴즈 1종
- 배지 3종, 이야기 책 화면

### 2단계: 가을·겨울 확장
- 팔공산·앞산 코스 추가 (예약 안내 포함)
- 한파 모드, 겨울 실내 코스
- 축제 연동 시즌 코스

### 3단계: 전국·접근성
- 이동 제약 사용자를 위한 접근성 기능 `[확인 필요]`
- 다른 도시 확장 가능성 검토

### 시연 시나리오 (3분)
1. 체감 36℃ 입력 → 실내 모드 전환 확인
2. 약령시 박물관에서 단서 획득
3. 계절 전환 (가을 입력) → 팔공산 코스 미리보기
4. 폭염특보 가정 → 안전 모드 확인
5. 이야기 책으로 마무리
