### 10. 스토리텔링 씨앗 (로컬 배경 작품 → 성지순례 → IP)

#### 10-1. 성지순례 성공 조건 (사례에서 확인된 것)
- 제작 단계부터 실제 장소를 정해 정밀하게 그리고, 현지와 협력했다 (누마즈: 필름커미션 협력, 엔딩 크레딧에 협력 시설명 표기)
- 홍보가 아니라 **작품이 먼저 재미있었다**. 지역은 나중에 반응했다
- 상점가가 **자발적으로** 캐릭터 장식과 상품을 만들었다 (누마즈·오아라이)
- 주민이 팬을 환영했다. 반대로 학교 무단 출입 같은 부작용도 있었다

#### 10-2. '억지' 판별 체크리스트 (에이전트 기획 규칙 후보)
1. **배경을 다른 도시로 바꾸면 이야기가 무너지는가?** 무너지지 않으면 억지다
2. **실화·설화·실제 풍경에 근거가 있는가?** 홍보를 위해 지어낸 설정이면 억지다
3. **홍보 문구 없이도 재미있는가?** 장소 소개가 대사로 나오면 억지다
4. **장면 속 장소들이 실제로 걸어서 이어지는가?** 이어지면 성지 동선이 생긴다
5. **장르로 번역되는가?** (청춘·로맨스·판타지·스포츠·음악·시대극)

> 반면교사: 대구시의 '도시브랜드 웹툰', '만화로 보는 대구 도로명 유래' 같은 공공 홍보 웹툰은 정보 전달용이라 1·3번을 통과하기 어렵다.

### 12. 유형별 첫 탐색 질문

키워드를 처음 조사할 때 던지는 질문이다. 각 질문이 브랜드의 어느 층위(정체성·페르소나·경험·감각·증거·리스크)를 채우는지 함께 적었다. 팀원 조사와 에이전트의 자료 수집 지시문에 같이 쓸 수 있다.

#### 12-0. 공통 질문 (모든 유형에서 먼저)
| 질문 | 얻는 것 |
|---|---|
| 대구와 어떤 근거로 연결되는가? (출신·역사·유래·소재·애정·홍보·배경) | 연관 근거 |
| 같은 이름이나 비슷한 대상이 다른 지역에 있는가? | 동명 혼동 방지 |
| 누가 권리(저작권·초상권·상표·시설 사용)를 갖고 있는가? | 리스크 |

#### 12-1. 유형별 질문

| 유형 | 첫 탐색 질문 | 채우는 층위 | 상위 씨앗 적용 예 |

| **역사** | ① 지금 남아 있는 공간·기록·유물은 무엇인가? | 증거·성지 동선 | 선교사 주택, 「동무생각」 악보, 평광동 사과나무 |

| | ④ 각색할 때 지켜야 할 사실과 바꿔도 되는 부분은? | 리스크 | 실존 이름 대신 가상 인물로 각색 |
| | ⑤ 실존 인물이면 권리·후손·평판 문제는 없는가? | 리스크 | 곡 저작권 확인 |

| | ② 언제 전성기였고 지금은 어떤가? (변화의 곡선) | 정체성(서사 긴장) | 교동 전자골목: 1980년대 후반~1990년대 후반 전성기, 이후 축소 |
| | ③ 방문객이 보고·만지고·살 수 있는 것은? | 경험·판매 | 공구 쇼핑, 로봇 체험(과학관) |
| | ④ 이 산업의 제품이 캐릭터·굿즈가 될 수 있는가? | IP 상품화 | 공구·부품 모티프 로봇 캐릭터 |
| **커뮤니티** | ① 누가 모이고, 언제·어디서 반복해서 만나는가? | 경험(반복 장면) | 공구골목 상인, 야시장 매대 운영자 |
| | ② 그들만의 말·의식·규칙·응원은? | 페르소나(언어) | 상인끼리의 호칭, 단골 문화 |
| | ③ 외부인을 어떻게 맞이하는가? | 리스크·수용성(성지순례 조건) | 촬영·방문을 반기는지, 꺼리는지 |
| | ④ 콘텐츠에 참여하거나 상품을 만들 의향이 있는가? | 판매·자발 참여 | 상점 등신대, 콜라보 메뉴 |

> 설계 원칙: 질문 하나가 키워드 카드의 필드 하나를 채우도록 했다. 자연 ①→`season`, ②→`sensory`, 역사 ③→`facts`/`story_hooks` 분리, 인물 ⑤·커뮤니티 ③→`caution`/`rights`. 이 필드명은 이후 브랜드 지식 파일의 자산 카드(키워드 1개 = 파일 1개, 사실과 해석을 분리한 YAML 형식)에 그대로 쓴다.
