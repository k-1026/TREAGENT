# 대구에서만 가능한 AI 에이전트 서비스 아이디어

- 작성일: 2026-11-09
- 조건
  1. AI 에이전트로 만들 수 있을 것
  2. 지역 이미지 개선, 홍보, 소상공인 도움 중 하나 이상에 기여할 것
  3. 지금까지 대구에 없었던 것
  4. 대구에서만 경험할 수 있어 차별성이 있을 것
- 표기: `[기존 확인]` 대구에 유사 사례가 있음, `[공백]` 검색 기준 유사 사례 없음, `[확인 필요]` 추가 조사 필요

## 1. 기존 대구 서비스 현황 (중복 피하기)

| 기존 서비스 | 성격 | 우리 아이디어와의 관계 |
|---|---|---|
| 대구시 AI 캐릭터 기자 '아이구' | 행정·문화 콘텐츠 | 캐릭터는 있으나 표준어 중심 `[기존 확인]` |
| 대구시 캐릭터 '패션이' | 시 캐릭터 | 생성형 AI로 리뉴얼만 실험 `[기존 확인]` |
| 대구시 민원 챗봇 '뚜봇', 120달구벌콜센터 생성형 AI | 민원 상담 | 관광·상권 특화 아님 `[기존 확인]` |
| 대구트립 앱 | 통합 관광·예약 | 역사 코스 포함, 운영 여부 확인 필요 `[기존 확인]` |
| 약령시 VR·AR 실감 체험관, 메타버스 축제 | 한방 체험 | 한의약 축제 중심 `[기존 확인]` |
| 칠성야시장 온라인 라이브 방송 | 축제 중계 | 실시간 방송만, 개인화 없음 `[기존 확인]` |
| 김광석길 벽화 교체·반짝 노래방 | 거리 체험 | AR 계획 확인 안 됨 `[공백]` |
| 민생홍보 크리에이터 (시 임기제 공무원 1명 채용) | 상권 홍보 숏폼 | 사람이 제작, 업체 지원 아님 `[기존 확인]` |
| 소상공인 AI 교육 (전국) | 교육 | 지역 전용 자동 제작 도구 없음 `[공백]` |
| 샵프로(SHOPRO) 등 전국 자동 홍보물 플랫폼 | 가게 홍보물 자동 생성 | 대구 맥락과 지역 데이터는 없음 `[확인 필요]` |

**공백 요약**
- 대구 사투리로 말하는 AI는 없습니다 `[공백]`.
- 소상공인 홍보물을 **대구 골목 맥락**으로 자동 만드는 서비스는 없습니다 `[공백]`.
- 장인의 구술을 AI로 정리해 지역 기록으로 남기는 서비스는 확인되지 않았습니다 `[공백]`.

## 2. 아이디어 목록

### A. 대구 사투리 골목 해설사 에이전트 ⭐ 우선 추천
- **무엇**: 대구 사투리로 골목과 가게를 설명하는 AI 해설사. 방문자가 고른 페르소나(예: 옛날 골목 할매, 동네 청년)에 따라 말투가 바뀝니다.
- **AI 에이전트 역할**: 장소 정보를 검수된 DB에서 가져오고, 사투리 말투로 바꿔 음성과 자막을 만듭니다.
- **지역 기여**: 사투리를 촌스러움이 아닌 **정체성 자산**으로 바꿉니다. 가게 소개도 함께 생성합니다. → 이미지 개선, 홍보, 소상공인
- **대구 고유성**: 대구 사투리 자체가 콘텐츠가 됩니다. 다른 도시로 옮길 수 없습니다.
- **리스크**: 사투리 데이터 확보, 희화화 금지 기준 필요, 말투가 지나치면 비하로 읽힐 수 있음
- **난이도**: 중 (데이터와 검수가 핵심)

### B. 골목 가게 홍보 에이전트 (사장님 한 줄 → 숏폼·카드뉴스)
- **무엇**: 사장님이 사진 몇 장과 한 줄 설명을 넣으면, 에이전트가 숏폼 대본, 카드뉴스, 소개 글을 만듭니다. 대구 행사(야행, 야시장)와 날씨를 자동으로 엮습니다.
- **AI 에이전트 역할**: 입력 수집 → 대구 맥락 결합 → 초안 생성 → 사장님 승인 후 게시 예약
- **지역 기여**: 소상공인이 직접 쓸 수 있는 홍보 도구입니다. 민생홍보 크리에이터 같은 인력 채용 없이도 골목 홍보가 가능합니다.
- **대구 고유성**: 대구 골목 데이터와 사투리 톤을 기본값으로 둡니다. 전국 플랫폼과 차별화됩니다.
- **리스크**: 전국 유사 도구 존재 (샵프로). 대구 데이터로 차별화해야 함. 과장 광고 방지 필요
- **난이도**: 하 (기술은 쉬움, 데이터 연결이 관건)

### C. 장인 구술 아카이브 에이전트 (약령시·염색·시장)
- **무엇**: 약재상, 염색 장인, 시장 상인의 이야기를 인터뷰로 받아 AI가 정리하고, 방문자가 들을 수 있는 짧은 이야기 카드를 만듭니다.
- **AI 에이전트 역할**: 인터뷰 녹취 → 요약 → 사실 확인 질문 생성 → 본인 확인 후 공개
- **지역 기여**: 사라져 가는 지역 기술을 기록합니다. 장인에게 **이야기의 주인으로서 출연료**를 줄 수 있습니다. 이미지 개선과 소상공인 홍보를 함께 합니다.
- **대구 고유성**: 대구의 약령시(360년), 섬유·염색, 서문시장 상인 이야기는 대구에서만 나옵니다.
- **리스크**: 구술 동의와 저작권, 개인정보. 본인 확인 절차 필수
- **난이도**: 중 (인터뷰 운영이 핵심)

### D. 우리 골목 주간 소식 에이전트
- **무엇**: 공개 데이터(행사, 날씨, 방문 추세)와 가게 소식을 모아 주간 골목 뉴스레터를 자동 생성합니다.
- **지역 기여**: 상인과 주민이 같은 소식을 공유합니다. 골목 신뢰도를 높입니다.
- **대구 고유성**: 대구의 야행, 야시장, 3호선 같은 지역 행사와 공간을 엮습니다.
- **리스크**: 데이터 출처 확인 필요. 폐업 등 민감한 정보는 공개 기준 필요
- **난이도**: 하

### E. 서문 옷골목 스타일 큐레이터
- **무엇**: 방문자의 취향과 예산으로 서문시장·동대구 옷 골목 가게를 조합해 코디를 추천하고, 가게 방문 쿠폰을 연결합니다.
- **지역 기여**: 의류 소상공인 판매 증대. 대구 패션 상권 이미지 강화.
- **대구 고유성**: 대구 섬유·의류 상권 기반
- **리스크**: 상업 추천이라 광고 표시 필요. 가게 선정의 공정성 문제
- **난이도**: 중
- **확인 필요**: 서문시장 온라인 판매 서비스와 중복 여부 `[확인 필요]`

### F. 대구 숫자 카드 에이전트 (편견 대신 데이터)
- **무엇**: 공공 데이터(방문객, 시장 수, 행사 규모)로 "대구는 이런 도시다"를 카드로 만듭니다. 사실 기반이므로 신뢰도가 높습니다.
- **지역 기여**: 지역 이미지를 데이터로 바로잡습니다.
- **리스크**: 지역 비하 논쟁과 맞물릴 수 있음. 숫자 선택 편향 주의. 정치적 해석으로 흐르지 않도록 기준 필요
- **난이도**: 하

### G. 더위 챌린지 코스 에이전트 (여름 역발상)
- **무엇**: 대구의 폭염을 콘텐츠로 바꿉니다. 그늘과 쉼터, 냉수 가게를 잇는 여름 코스를 만들고, 완주 시 가게 쿠폰을 줍니다.
- **지역 기여**: 여름 비수기 상권 활성화. 방문자 안전 정보 제공
- **대구 고유성**: 대구 기후가 핵심 콘텐츠입니다.
- **리스크**: 기존 보급소 아이디어와 겹침. 폭염 안전 정보 정확도 필요
- **난이도**: 중

### H. 야구 날 골목 응원 에이전트
- **무엇**: 대구 홈경기 결과에 맞춰 골목 응원 메시지와 가게 쿠폰을 자동 생성합니다.
- **지역 기여**: 경기 날 상권 연계. 응원 문화 강화
- **대구 고유성**: 대구는 야구 도시입니다.
- **리스크**: 구단 상표와 IP 사용 제약. 일반 응원 표현으로 써야 함. 구단 협의 필요
- **난이도**: 중 (권리 확인이 선행)

## 3. 우선순위 제안

| 순위 | 아이디어 | 이유 |
|---|---|---|
| 1 | A. 사투리 골목 해설사 | 대구 고유성이 가장 강하고 기존 캐릭터와 명확히 다름 |
| 2 | B. 골목 가게 홍보 에이전트 | 소상공인에게 바로 효용, 기술 난이도 낮음 |
| 3 | C. 장인 구술 아카이브 | 지역 이미지와 기록을 동시에 잡음 |

**조합 제안**: A의 사투리 말투와 B의 가게 홍보 데이터를 같은 DB로 묶으면, 해설과 홍보가 한 흐름으로 이어집니다.

- [ ] 장인 구술 아카이브의 기존 대구 사례 (대구문화재단, 중구청 기록 사업)

## 5. 주의

- 본 문서는 검색 요약 기준입니다. `[공백]` 판단은 검색 결과에 없었다는 뜻이며, 실제로 없다는 확인은 아닙니다.
- 사투리 콘텐츠는 지역 정체성을 살리되, 희화화하지 않는 기준을 먼저 정해야 합니다.
- 장인 구술과 상인 정보는 본인 동의와 확인이 있어야 공개합니다.
