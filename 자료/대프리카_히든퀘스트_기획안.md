# 대프리카 히든 퀘스트 (DAEPRICA HIDDEN QUEST) 기획안

- 작성일: 2026-11-09
- 기반 아이디어
  - (A) 대구 히든 퀘스트: 사용자 위치와 취향에 맞춰 대구 실제 장소로 미션과 스토리를 생성하는 AI 에이전트
  - (B) 대프리카 서바이벌: 대구의 폭염을 도심 생존 챌린지로 바꾸는 AI 에이전트
- 합친 방향: **더위를 피해 다니는 도시 탐험 RPG.** 날씨가 퀘스트 경로를 바꿉니다. 더우면 그늘과 실내로, 선선하면 골목으로 나갑니다.
- 표기: `[검증됨]` 공공 자료 또는 보도 확인, `[확인 필요]` 추가 조사 또는 협의 필요

## 1. 한 줄 컨셉

> **"오늘 대구는 40도다. 그래도 퀘스트는 시작된다."**
> 폭염일수록 게임은 실내와 그늘을 골라 줍니다. 날씨가 곧 난이도이자 지도입니다.

## 2. 타겟 설정

### 주 타겟 (1순위): 대구 거주 2030 직장인·대학생
- 점심시간, 퇴근 후 60분 산책을 원하는 사람
- 게임과 산책을 좋아하지만 무리한 야외 활동은 싫어함
- 여름에 집 밖이 힘들어서 실내 활동을 찾는 사람
- 선정 이유: 가장 자주 플레이할 수 있고, 장소 탐색 동기가 뚜렷함

### 보조 타겟 (2순위): 대구 방문 2030 혼행객 (1박 2일)
- 대구 첫 방문, 도심 중심으로 움직이는 사람
- 선정 이유: 30~60분 코스가 여행 일정에 맞음. 다만 날씨 정보를 믿고 움직이므로 안전 안내 신뢰가 중요함

### 제외 (이 서비스의 대상이 아님)
- 폭염 취약 계층 (고령자, 어린이 단독 활동, 야외 노동자): 게임보다 안전 안내가 우선. 별도 안내 서비스로 다룸
- 가족 단위 어린이 이용자: 방한·안전 기준이 달라서 이번 버전에서는 제외

## 3. 핵심 게임 루프

```
현재 위치 + 체감온도 + 시간 + 취향 입력
        ↓
날씨 규칙 엔진이 모드 결정 (아래 표)
        ↓
장소 DB에서 검수된 장소만 골라 퀘스트 생성
        ↓
단서 찾기 → 미션 수행 (사진·퀴즈·현장 인증)
        ↓
진행 중 날씨 변화에 따라 경로 수정
        ↓
배지 + 모험 기록 (개인 이야기 책)
```

### 날씨 모드

| 조건 (체감온도 기준) | 모드 | 퀘스트 방식 |
|---|---|---|
| 28℃ 미만 | 탐험 모드 | 골목·시장 야외 미션, 최대 60분 |
| 28~33℃ | 그늘 모드 | 나무 그늘, 지하·실내 경로 우선, 야외 구간 짧게 |
| 33℃ 이상 | 실내 모드 | 쉼터, 카페, 박물관, 3호선 등 실내 중심. 야외 구간은 짧은 이동만 |
| 폭염특보 발령 | **안전 모드** | 게임 일시 중지. 쉼터 안내, 물 섭취 알림, 귀가 안내 우선 |
| 야간 | 야행 모드 | 야경, 야시장 미션 |

> 기준 수치는 기상청과 보건 기준을 확인한 뒤 확정합니다 `[확인 필요]`.
> 폭염특보가 나오면 게임보다 안전이 먼저입니다. 이 규칙은 AI가 아니라 **규칙 엔진**이 담당합니다.

## 4. 코스 설계 추천

### 코스 A. 기본 MVP 코스: "사라진 대구의 비밀 레시피" (중구, 30분)
- **스토리**: 옛 약재와 음식 레시피가 골목에서 사라졌습니다. 단서를 따라 장소를 찾으세요.
- **장소 5곳**
  1. 동성로 (시작, 단서 1: 옛 간판 찾기)
  2. 근대골목 (단서 2: 근대 건물 사진 맞추기 퀴즈)
  3. 대구약령시한의약박물관 권역 (단서 3: 약재 이름 맞추기, 실내 미션으로 대체 가능)
  4. 서문시장 (단서 4: 시장 음식 사진 인증)
  5. 계산성당 또는 근대골목 종점 (마지막 단서, 완료 배지)
- **날씨 대응**: 33℃ 이상이면 약령시 박물관을 먼저 방문하고 야외 구간을 줄입니다.
- **확인 필요**: 구간 거리와 실제 보행 시간 `[확인 필요]`. 중구 골목투어 코스와 겹치므로 중구청 협의 필요.

### 코스 B. 여름 그늘형: "그늘을 찾아라" (수성구, 60분)
- **스토리**: 도심의 열기를 피해 숨은 그늘을 찾는 임무입니다.
- **장소 흐름**: 동대구·반월당 등 3호선 환승역 → 3호선 탑승 미션 (실내 이동) → 수성못 나무 그늘 산책 → 쉼터 확인 미션
- **장점**: 수성못은 나무 그늘이 넓어 도심보다 덜 더웠다는 현장 취재가 있습니다 `[검증됨: 영남일보 현장 취재, 2026-07]`.
- **3호선 활용**: 냉방이 되는 이동 수단이라 폭염일에 야외 구간을 줄이는 장치로 씁니다. 이 기획서의 3호선 콘텐츠와도 이어집니다.

### 코스 C. 야행 코스: "야시장 암호 해독" (중구·서문, 45분)
- **스토리**: 야시장 상인들의 암호문을 해독해 다음 장소를 찾습니다.
- **장소 흐름**: 서문야시장 → 근대골목 야경 → 계산성당 야경
- **날씨 대응**: 야간은 야행 모드로 바뀌며, 더위가 가신 시간대에 맞춰 추천합니다.
- **확인 필요**: 서문야시장 운영 요일 (금·토·일 여부 기사마다 다름) `[확인 필요]`

### 코스 설계 원칙
- 한 코스는 **30~60분**, 장소 **4~6곳**
- 야외 구간은 **연속 15분 이하**로 설계 (폭염 대비)
- 모든 장소에 **실내 대체 경로**를 하나 이상 둠
- 장소 정보는 **검수된 DB**에서만 가져옴. AI가 장소를 새로 만들지 않음

## 5. 게임 요소

- **시즌제**: 여름 시즌은 "대프리카 서바이벌", 가을 시즌은 "히든 퀘스트" 등 주제를 바꿈
- **배지**: "그늘 장인", "실내 탐험가", "중구 골목 해독자"처럼 날씨 대응 행동에 배지 부여
- **생존 지표**: 물 섭취, 쉼터 방문, 무리한 야외 시간 줄이기 등을 "체력" 대신 **안전 점수**로 표시. 높을수록 보상이 많음 (단, 야외 시간을 늘리도록 유도하지 않음)
- **모험 기록**: 완료 장소와 단서를 모아 **개인 이야기 책**으로 묶음 (기존 기획의 핵심 기능과 연결)
- **팀 모드**: 2~4명이 같은 단서를 나눠 찾는 방식 (2030 친구 모임용)

## 6. AI 에이전트 구조

| 단계 | 담당 | 역할 |
|---|---|---|
| 입력 | 사용자 | 위치, 시간, 취향 (역사·음식·음악·사진 등) |
| 환경 판단 | **규칙 엔진** | 체감온도, 폭염특보 확인 → 모드 결정 |
| 장소 선택 | 규칙 + 검수 DB | 모드에 맞는 장소만 필터링 |
| 퀘스트 생성 | AI 에이전트 (LLM) | 스토리 문장과 미션 문구 생성 (사전 검수된 템플릿 안에서) |
| 진행 관리 | 규칙 엔진 + AI | 날씨 변화 시 경로 수정, 사용자 상태에 따라 난이도 조정 |
| 기록 | 저장소 | 배지, 완료 기록, 개인 이야기 책 |

**설계 원칙**
- 안전 규칙은 AI가 바꿀 수 없습니다. 폭염특보 시 게임을 멈추는 규칙은 고정합니다.
- LLM은 **문장**만 만들고, 장소와 쉼터 정보는 DB에서만 가져옵니다. 역사 설명이 틀렸다는 보도가 있었던 점을 반영한 것입니다.
- 위치 정보는 **사용 중에만** 수집합니다. 백그라운드 추적은 하지 않습니다.

## 7. 장점과 단점

### 장점
- **지역 정체성**: 대구의 더위를 약점이 아니라 콘셉트로 바꿈
- **날씨가 콘텐츠가 됨**: 같은 장소도 날씨에 따라 다른 퀘스트. 재방문 동기가 생김
- **실내 연결**: 쉼터, 박물관, 3호선을 게임 무대로 씀. 더위 피난처가 곧 콘텐츠
- **안전 중심 설계**: 폭염 시 게임을 멈추는 규칙이 있어 신뢰를 얻기 쉬움
- **해커톤 데모 용이**: 장소 5곳과 날씨 규칙만으로 MVP 시연 가능
- **기존 기획과 연결**: 3호선, 근대골목, 개인 이야기 책과 바로 이어짐

### 단점과 리스크
- **안전 책임**: 게임 중 열사병 등 사고가 나면 서비스 책임 문제가 생길 수 있음 → 안전 안내 문구, 면책 고지, 폭염 시 게임 중지 기준 필요
- **쉼터 정보 정확도**: 대구 무더위쉼터 1,196곳 중 오후 6시 이후까지 운영하는 곳은 235곳(19.6%), 24시간 운영은 5곳뿐이었음 (매일신문, 2026-08 기준). 운영 시간 정보를 자주 검증해야 함 `[검증됨]`
- **위치 권한 부담**: 위치 권한을 요구하면 이탈이 큼. 사용 중에만 수집하고, 설명을 명확히 해야 함
- **날씨 의존성**: 맑은 날과 폭염일의 콘텐츠 양이 다르므로 장소 DB를 넉넉히 확보해야 함
- **기존 서비스와 비교**: 부산 중구 스마트 관광전자지도는 위치 기반 자동 스탬프와 완주 인증서를 이미 제공함. 차별점은 **날씨 기반 경로 변경과 생성형 스토리**여야 함 `[검증됨: 앱스토어 설명]`
- **상업성**: 가게 제휴가 없으면 운영비 회수가 어려움. 다만 소상공인 연계는 필수는 아님

## 9. 권장 MVP 범위 (해커톤 기준)

### 포함
- 장소 DB 15~20곳 (중구 중심, 검수 완료)
- 날씨 규칙 엔진 (체감온도 + 폭염특보 연동)
- 코스 A 1개 + 실내 대체 경로
- 퀘스트 문장 생성 (사전 검수 템플릿 안에서)
- 사진 인증 1종, 퀴즈 1종
- 배지 3종과 간단한 이야기 책 화면

### 제외 (다음 단계)
- 실시간 다중 사용자 기능
- 가게 제휴 쿠폰
- 야간 코스의 실제 상시 운영
- 전국 확장

### 시연 시나리오 (3분)
1. 체감 36℃ 상황 입력 → "실내 모드" 자동 전환 확인
2. 약령시 박물관에서 단서 1 획득
3. 폭염특보 가정 → 게임 중지, 쉼터 안내 확인
4. 이야기 책 화면으로 마무리

## 11. 주의

- 폭염 관련 수치는 2026년 보도 기준이며, 최신 데이터로 다시 확인해야 합니다.
- 게임 요소가 야외 활동을 늘리도록 설계되면 안 됩니다. 보상은 **안전 행동**에 주고, 무리한 야외 시간에는 보상을 주지 않습니다.
- 이 문서는 기획 단계입니다. 장소, 거리, 운영 시간은 현장 확인 전 추정치입니다.
