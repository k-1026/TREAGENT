# 동물형 SD 캐릭터 후보 v1 (대구 특징 기반)

- 작성일: 2026-11-09
- 형식: 동물형 SD (2~3등신, 큰 머리, 단순한 선)
- 표기: 대구 특징은 근거 id 괄호, 이름·성격·말버릇은 **창작 후보 2개씩**. 팀이 고름.
- 공통 금기: 상표·설비명을 이름으로 쓰지 않음. 기존 IP(도달쑤, 뚜비, 리카, 빅디)와 닮지 않게 함.

## 1. 땡볕 매미 (여름의 소리)
- 대구 특징: 여름 감각의 기억으로 매미 소리가 나옴 (keyword_map.md:442). 더위 해소 서사의 축 (대프리카_히든퀘스트_기획안.md:19)
- 이름 후보 (창작): 맴맴이 / 땡볕이
- 성격 (창작): 씩씩한 · 시끄럽지만 따뜻한 · 여름을 좋아하는
- 말버릇 (창작): "맴맴! 그늘 어디 있나 볼까요?" / "오늘도 더워야 재밌죠"

## 2. 홍옥 다람쥐 (사과 도시)
- 대구 특징: 1899년 무렵 선교사가 들여왔다는 사과 이야기 (keyword_map.md:200). 평광동 홍옥나무 (keyword_map.md:200)
- 이름 후보 (창작): 홍옥이 / 평광이
- 성격 (창작): 꼼꼼한 · 동그란 · 욕심 없는
- 말버릇 (창작): "빨갛게 익을 때까지 기다려 봐요" / "한 입만 먼저 찾아볼까요?"

## 3. 바삭 닭 (치킨 도시)
- 대구 특징: 처갓집양념치킨, 호식이두마리치킨 등 대구 출발 브랜드 (keyword_map.md:248). 치맥페스티벌 (keyword_map.md:207)
- 이름 후보 (창작): 바삭이 / 꼬꼬돌
- 성격 (창작): 신나는 · 장난스러운 · 의리 있는
- 말버릇 (창작): "바삭! 맥주 한 잔 먼저 찾아볼게요" / "축제는 같이 가야 맛이죠"
- 주의: 브랜드명·상표 노출 금지. 발상지 주장은 자료마다 다르므로 대사에 쓰지 않음 (keyword_map.md:248)

## 4. 약이 사슴 (약재 골목)
- 대구 특징: 1658년 개설된 약령시와 약재 골목 (keyword_map.md:252). 한방문화축제 (crosscheck.md:16)
- 이름 후보 (창작): 약이 / 녹이
- 성격 (창작): 차분한 · 아는 게 많은 · 다정한
- 말버릇 (창작): "이 약재는 골목 어디에 숨어 있을까요?" / "천천히 걸으면 보이는 것이 있어요"

## 추천 (팀 결정 전)
- 1순위: 땡볕 매미. 여름 더위 해소 서사와 가장 직접 연결되고, 소리라는 감각을 캐릭터로 쓸 수 있음.
- 2순위: 바삭 닭. 음악·축제 훅과 연결되기 쉬움.
- 3순위: 홍옥 다람쥐 · 약이 사슴. 역사 테마 후반 배치와 맞춤.
