# 게임 요소 후보 v1 (돋보기·모자·대구 요소)

- 작성일: 2026-11-09
- 목적: 히든 퀘스트 게임 컨셉을 살리는 도구와 아이템 후보
- 표기: 대구 요소는 근거 id 괄호. 게임 도구·액세서리는 **창작 후보**.

|---|---|---|---|---|

## 추천 (팀 결정 전)
1. **돋보기**: 게임 컨셉(탐정, 단서 찾기)과 가장 직접 맞음
2. **손선풍기**: 대구 여름 더위를 가장 잘 살린 요소
3. **능금 열매**: 수집 보상이 사과 도시와 연결됨

- 탐정 모자는 캐릭터 꾸미기용으로 추가 가능
- 약재 주머니와 3호선 승차권은 테마 배치에 맞춰 추후 추가
