# brand/cutscene — 컷씬 일러스트 (라인아트 애니메이션)

- 고정 컷씬에 쓸 일러스트 시안을 둡니다. 컷씬은 미리 지정해 두는 고정 컷씬이고 에이전트가 생성하지 않습니다 (brand/worldview.md 3-5절).
- 그림 방식: SVG 선화 애니메이션 (얇은 잉크 선, 따뜻한 종이색, 포인트는 능금 빨강). 파일 하나로 열립니다 (html 안에 코드 포함).
- 상태: **창작 시안**입니다. 하나로 확정하지 않았고 결정은 팀이 합니다.

## 컷씬 ② 장면 구성 (창작)

- 근거: 납작만두 가게 앞 그늘에서 하랑이가 숨을 고르는 장면, 지친 일은 앉아서 숨을 고르는 정도로 가볍게, 대사 없음 (brand/worldview.md 3-5절 컷씬 ②, 연출 기준).
- 시간 흐름:
  - 0~3초: 한낮 골목. 하랑이가 땀을 흘리며 헐떡이고 손으로 부채질합니다. 이파리가 처져 있습니다 (신호 규칙: brand/character/profile/harangi_character.md 8절 예문 18).
  - 2.5~5초: 가게 창가의 주인이 팔을 내밀어 의자 등받이에 천 주머니를 걸고 들어갑니다. 주인은 실루엣과 팔로만 나옵니다. 하랑이를 보지 못한 채 베푸는 호의입니다 (worldview.md 3-5절 후보 A).
  - 5~8초: 하랑이가 걸린 주머니를 올려다보고, 걸상 위 물 컵 쪽으로 조금 다가앉아 컵을 잡습니다.
  - 8~10초: 눈을 감고 한 모금 마신 뒤 숨을 내쉽니다 (바람 은유: worldview.md 1절).
  - 10초 이후: 컵을 무릎에 올리고 이파리가 선 채로 천천히 숨 쉽니다.
- 설정과 맞춘 점:
  - 견습생이 되기 전의 일이라 **부채, 후드 조끼, 포쉐트를 그리지 않았습니다.** 포쉐트는 이 주머니를 받아 만든 선물이기 때문입니다 (worldview.md 3-5절, harangi_character.md 6절).
  - 쓰러짐, 웃음거리, 참사·공포 연출을 쓰지 않았습니다 (CLAUDE.md 민감한 소재).
  - 실제 가게 이름과 위치를 쓰지 않았습니다. 간판의 "납작만두"는 음식 이름입니다 (worldview.md 3-5절 공통).
  - 정령의 수나 도사의 수를 화면에 넣지 않았습니다 (worldview.md 2-1절, 3-3절).

## 결정 필요

- [ ] 주인 표현 범위: 지금은 창 안의 어두운 실루엣 + 팔입니다. 규칙은 "손이나 그림자로만"이고, "게임에는 하랑이만 등장" 원칙과의 관계는 `[확인 필요]` (worldview.md 3-5절).
- [ ] 이 컷에서 하랑이가 주머니를 받는지: 지금은 걸어 두는 데서 끝납니다. 받아서 두르는 장면은 다음 컷 후보입니다.
- [ ] 시각 방향: 이 시안은 6-3절 후보 1(종이 질감 + 능금 빨강 포인트)에 가깝게 그렸습니다. 팀이 후보를 고르기 전 시안입니다 (harangi_character.md 6-3절).
- [ ] 간판 글꼴: 보는 기기의 시스템 한글 글꼴을 씁니다. 손글씨 느낌이 필요하면 간판 글자를 직접 그린 선으로 바꿉니다.
- [ ] 이어서 그릴 컷 후보 (창작): 컷씬 ① 첫 쉼터(견습생 외형, 부채 있음) / 첫 만남 쉼터(worldview.md 4-7절) / 엔딩.

## 확인 필요

- 배포 전 확인: 개인정보, 허가받지 않은 실존 인물·가게 이름이 없습니다 (이 시안은 가상 가게, 실루엣만 나옴). 이미지 파일을 쓰지 않아 EXIF 문제가 없습니다.
- 모션 줄이기 설정을 켠 기기에서는 마지막 장면(쉬는 모습)에 멈춰 보입니다.
