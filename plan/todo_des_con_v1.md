## 2. 이번에 정해진 것 (2026-11-17)

- 코스는 장소 3곳, 도장은 한 코스에 3개. 장소를 방문해 **미션을 마칠 때** 도장 1개를 받습니다 (S-18).
- **방문 인증 = 미션 수행.** 인증 방식은 GPS + 미션입니다 (GPS로 도착 확인 후 미션).
- 진행 중 새 길을 고르면 **경고창을 띄운 뒤** 새로 시작할 수 있습니다 (D-08).
- 지금 MVP는 **중구만**. 권역 구분·완주 조건·권역별 달성률은 추후 논의입니다.
- 장부 구성: 책갈피 [칸] [내 여행] [앨범], 주머니는 홈 버튼. 장부 탭 = 장부 전체, 방 안 장부 그림 = 오늘 페이지.
- 길동무 수는 **장소(칸) 단위**로만 보여 줍니다 (코스 합산 없음).

### E. 소정에게 전달할 것 (개발 반영 요청)

- 도장은 코스당 3개이고 미션 완료 때 서버가 판정 (서버·DB 트랜잭션, 세션·장소 유일).
- 인증 = GPS 도착 확인 + 미션. GPS만으로는 도장 없음.
- 진행 중 새 여행: 경고 후 새로 시작. 하던 여행의 처리 방식은 `[결정 필요]`.
- 홈용 응답: 날씨 배지(지역, 기준 시각, AWS 여부), 오늘의 추천 길(모드별 필터, 1~3개), 쉼터 목록.
- 장부 [칸]은 장소 단위 집계. 시간대 구분이 정해져야 집계 키가 정해집니다.
- 중구 밖이면 "지금은 중구만 안내해요" 상태.
- 장소마다 미션 종류(영수증형/퀴즈형)와 미션 내용을 담을 자리: 지금 `places` 테이블에는 미션 컬럼이 없습니다. 장소 목록이 확정되면 함께 설계 (민지의 조사 결과 기준).
- 모드표 통합(D-06): 코드는 28℃/33℃ 임시값, 명세는 시나리오 5가지.
- 시드 코스 제목(후보 A/B)과 소요 시간 확정 후 반영.
