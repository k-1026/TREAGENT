# 스토리보드 결정 요약 v1

- 작성일: 2026-11-23
- 목적: 2026-11-20~23 사이 목업, 컷씬, 스프라이트 작업에서 정한 내용과 아직 정하지 않은 내용을 한 곳에 모읍니다. 세부 근거는 각 원문을 봅니다.
- 상태: 정리본입니다. 확정 항목도 팀 검토 전에는 `[확정(작업자)]`로 표시합니다.

## 1. 확정된 내용

### 1-1. 홈 목업 (`storyboard/app_home_mockup_v1.html`)

- **방문 인증 실패 (S-06)**: 권한 꺼짐, 측위 실패, 거리·정확도 문제, 응답 누락을 사유별 카드로 보여 줍니다. "다시 확인"을 누르면 미션 화면으로 돌아갑니다. 목업 반영 완료 (커밋 `721d080`).
- **하랑이 말풍선**: 하랑이를 누르면 새 화면 없이 말풍선에 승인 대사 한 줄을 무작위로 보여 줍니다. 대사 목록은 이용자 화면에 보이지 않습니다. 날씨에 따라 공통 2개와 날씨별 2개(폭염, 호우, 날씨 확인 불가, 보통)를 섞어 고릅니다. 말풍선을 누르면 닫힙니다 (커밋 `b722b17`, `d283541`).
- **지역(구·군) 변경 (F-23)**: 구·군 9개를 칩으로 한 화면에 보여 줍니다. 중구만 선택되어 있고, 나머지는 "준비 중"으로 막혀 있습니다. 화면 상단에 현재 날씨 요약이 있습니다 (커밋 `365d1ef`, `d283541`).
- **홈 날씨 배지**: 날씨와 지역(중구)을 함께 보여 줍니다. 배지를 누르면 지역 변경 화면으로 갑니다. 창문으로 날씨 상세에 가던 연결은 뺐습니다 (커밋 `d283541`).
- **내 정보**: 닉네임은 "잠김" 표시로 바꾸고 수정 버튼을 없앴습니다. 로그아웃은 확인 박스(로그아웃/취소)를 거칩니다 (커밋 `d283541`).
- **PR #198**: 위 목업 변경을 담은 PR입니다. `dev`에 병합되었습니다 (merge commit `593f8e1`).

### 1-2. 컷씬 (`storyboard/game_flow_story_v1.md` 9-1절)

- **컷씬 A (첫 만남 쉼터 회상)**: 두 번째 여행의 중반, 두 번째 곳의 도장을 찍은 뒤 다음 곳으로 가기 전에 한 번 재생합니다 (사용자 결정 2026-11-23). 커밋 `0bbfaf0` (브랜치 `feat/storyboard-cutscene-timing`, 아직 푸시하지 않음).
- **형식**: 1편 1컷, 세로 전체 화면, 깔끔하고 귀여운 2D 일러스트. 라인아트 스킬은 쓰지 않습니다 (사용자 결정 2026-11-23). 장면이 움직임을 필요로 하면 같은 장면 안에서 최대 3컷입니다.
- **재생 방식**: 건너뛰기 가능, 건너뛰어도 앨범에 저장됩니다. 재생 뒤에는 앨범에서만 다시 봅니다. 해금은 계정 기준 개인 진행입니다 (9-2절).
- **기본 프롬프트**: `brand/cutscene/cutscene_base_prompt_v1.md` (초안, 팀 확인 전).

### 1-3. 캐릭터와 스프라이트

- **채택 스프라이트**: 장부 (펼침, `brand/images/items/ledger_sprite_v1.webp`), 덮인 장부 (`ledger_closed_sprite_v1.png`), 능금 (`nunggeum_sprite_v1.png`), 하랑이 꼬리 (`harangi_tail_sprite_v1.webp`), 열쇠 (`key_sprite_v1.png`), 부채 (`fan_sprite_v1.png`), 납작만두 (`dumpling_sprite_v1.png`). 투명 배경은 사용자가 확인했습니다. 메타데이터는 `archive/metadata.csv`에 등록했습니다 (커밋 `80b8592`, `88df0b3`, 브랜치 `feat/brand-sprite-assets`, 푸시 대기).
- **꼬리 조건**: 몸과 같은 능금 빨강, 끝 3분의 1만 크림색. 얼굴과 배는 크림색 (`brand/character/prompts.md` 공통 조건).
- **준비물 아이콘**: 9종 (생수, 캡모자, 양산, 선크림, 쿨토시, 우산, 여벌 양말, 운동화, 겉옷). 시트 `brand/images/items/travel_items_sheet_v1.webp`.

## 2. 결정 필요

- [ ] **하랑이를 누르면 대사가 나오는 동작**: 명세 F-13에는 이 동작이 없습니다. 목업은 말풍선 무작위 방식으로 만들었습니다. 팀 확인 필요 (`plan/spec/treagent_tech_spec_v1.md` F-13).
- [ ] **지역 변경 화면을 남길지** (F-23): 지금은 중구만 선택 가능합니다. 변경 화면 자체를 빼거나 유지할지 정해야 합니다.
- [ ] **날씨 상세 화면(S-14 날씨)의 진입 경로**: 창문 연결을 뺐기 때문에 지금은 어디에서도 열리지 않습니다. 화면을 살릴지, 뺄지 정해야 합니다.
- [ ] **닉네임 기본값과 건너뛰기 문구**: 목업은 닉네임 필수, 변경 불가입니다. 앱(`dev/app/src/app/welcome.tsx`)에는 건너뛰기와 기본값 "길동무"가 남아 있습니다 `[확인 필요: 소정님]` (`storyboard/design_system_v1.md` 18절).
- [ ] **컷씬 ② 재생 시점**: 첫 완주 직후(추천)와 두 번째 여행 시작 때 중 하나를 정해야 합니다 (`game_flow_story_v1.md` 9-1절).
- [ ] **막별 컷씬 채택 여부**: 채택하면 컷씬이 늘고 앨범 해금 규칙이 바뀝니다 (`worldview.md` 5-4절, `game_flow_story_v1.md` 10-3절).
- [ ] **가게 주인 표현 범위**: 실루엣과 팔만 쓸지 정해야 합니다 (`brand/cutscene/README.md`, `[확인 필요]`).
- [ ] **앨범 화면 명세 추가 승인**: 아직 체크되지 않았습니다 (`game_flow_story_v1.md` 12절).
- [ ] **능금 모티프 사용 허가**: 스프라이트 사용 허가 범위를 확인해야 합니다 (`brand/decision_nunggeum_motif_v1.md` 55~56행, `archive/metadata.csv`의 "확인 필요" 항목).
- [ ] **하랑이 대사 문장 승인 (B1)**: 지금은 모두 승인 대기 자리입니다. 날씨별 대사 문장은 팀이 정합니다.
- [ ] **운영자 웹 역할 분담**: 소정님과 FE·BE 역할을 나눠야 시작할 수 있습니다 (준비 중 목록 A-3).
- [ ] **앱 이식 인계**: 민지 조원이 목업을 앱에 옮깁니다. 이식 기준 브랜치와 열린 결정 목록(위 2번 항목)을 함께 전달해야 합니다. `design_system_v1.md` 16절 절차를 따릅니다.
