# 여행 저장·방문·완주 결정 요청 v1

[여행 저장·방문 인증·완주 설계 v1](trip_visit_design_v1.md) 9장의 결정 필요 10개를 회의에서 바로 고를 수 있게 정리했습니다.

- **이 10개가 정해져야** 여행 저장, 방문 인증, 완주, 장부 [내 여행], 앨범을 만들 수 있습니다. 지금 장부·앨범이 늘 비어 있고 앱을 다시 켜면 걷던 여행이 사라지는 이유입니다 (설계 v1 1장).
- 정할 순서대로 3묶음으로 나눴습니다. **1묶음(3개)만 정해도 DB 작업을 시작할 수 있습니다.**
- 각 항목: 질문 → 선택지와 영향 → 자료에 이미 있는 것 → 결정 기록 칸. 이 문서는 어느 쪽도 고르지 않습니다. 자료에 추천이 있는 곳만 "자료 추천"으로 적었습니다.

### ① 도장은 무엇마다 1개인가요?

|---|---|
