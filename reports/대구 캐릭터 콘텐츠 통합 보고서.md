## 0. 한눈에 보는 논리

1. **문제:** 도달쑤는 설정이 있지만 그 설정을 쓴 콘텐츠와 판매 경로가 부족하다.
2. **원인:** 캐릭터는 그림만으로 뜨지 않는다. **매력이 애착을 만들고, 운영이 애착을 수익으로 바꾼다.** 도달쑤는 두 단계가 모두 약하다.
3. **숫자가 주는 교훈:** 수익은 조회수가 아니라 상품과 라이선스에서 나온다. 다만 초기 화제는 빠르게 식고, 판매액이 곧 공공 수입도 아니다.
4. **포지셔닝:** 그래서 도달쑤를 **"대구 골목의 먹거리를 알려 주는 참견쟁이 수달"** 로 잡는다. 하모(축제), 뚜비(생태)와 겹치지 않고 공식 프로필도 살린다.
5. **인물:** 애착이 쌓이도록 옷이 바뀌어도 도달쑤는 한 명으로 둔다. 성격의 다양함은 사장님과 단골이 맡는다.
6. **콘텐츠:** 대구의 더위·시장·무뚝뚝한 정을 일터 시트콤 「도달쑤 일일 알바」(가제)로 만든다.
7. **제작:** 같은 얼굴과 안정된 표정이 웃음의 기반이므로, 사람이 만든 파츠를 AI가 조합한다.
8. **유통:** 흔한 심리테스트 대신 알바 면접 → 일터 배치 → 먹거리 코스 → 현장 방문 → 상품으로 잇는다.
9. **사업:** 비용이 적은 이모티콘부터 시작해 반응에 따라 넓힌다. 시 허가가 없어도 진행할 수 있게 우리 소유 조연을 함께 만든다.
10. **지속:** 권리, 상표, 후속 예산, 단체장 교체 대비를 먼저 정한다.

> 핵심 문장: **"대구에서 일하는 건 덥고 고된데, 사장님이 결국 밥은 챙겨 준다."**

## 1. 문제: 도달쑤는 왜 덜 알려졌나

**현재 상태**
- 대구시 대표 캐릭터로 쓰이지만 공식 지정 문서는 찾지 못함 (2022년 시 입장은 "공식 아님")
- 2022년 기준 전담 2명, 개발·활동 예산 0원, 수익사업 불허
- 시 페이지 이용 조건: 공공누리 제2유형(출처표시 + 상업적 이용금지)
- 간접 비교: 2021년 이모티콘 배포에서 하모 5만 개 13분, 달쑤 4.5만 개 1시간 30분

**원인 (`추론`)**
- **콘텐츠 부족:** 프로필은 있으나 그 설정이 장면으로 쓰이지 않음
- **판매 경로 부족:** 뚜비(구 캐릭터)가 광역시 캐릭터보다 먼저 굿즈 성과를 냄
- **위치가 불명확:** 수달은 하모와 겹치고, "친환경 도시" 메시지도 일상에서 찾을 이유가 약함

**→ 따라서** 질문은 "새 그림을 어떻게 만들까"가 아니라 "왜 좋아하게 되고, 어떻게 돈과 방문으로 이어지나"이다.

## 2. 성공과 실패는 어떻게 갈리나

**두 관점을 단계로 합친다 (`추론`)**
- 박민지 자료: 성패는 운영 구조가 가른다.
- 기획 보고서: 인기 작품은 충돌·결핍·관계로 구별된다.
- 통합: **매력 → 애착 → 지속 운영 → 살 수 있는 상품 → 수익.** 어느 한 단계가 끊겨도 실패한다.

### 2-1. 왜 좋아하게 되나: 차별화 원리 6가지 (`추론`)

| 원리 | 뜻 | 사례 |
|---|---|---|
| 겉과 속의 충돌 | 귀여운 외형 × 고된 현실 | 치이카와의 노동과 위협, 레츠코의 데스메탈, 잔망루피의 험한 말 |
| 결핍이 정체성 | 강점보다 약점으로 기억됨 | 스미코구라시의 콤플렉스, 꺅두기의 슬픈 눈, 브레드이발소 손님의 외모 고민 |
| 현실 제도를 세계관에 | 아는 제도가 웃기고 아픔 | 치이카와의 풀 뽑기 검정, 펭수의 연습생, 브레드이발소의 직장 문화 |
| 비워 두기 | 다 설명하지 않아 해석이 생김 | 리락쿠마의 지퍼, 치이카와의 적은 대사, 가나디의 미완성 같은 그림 |
| 관계가 이야기 | 인물 사이 긴장이 소재를 낳음 | 틴틴팅클의 다툼, 농담곰의 자기 츳코미, 꺅두기와 닥터후 |
| 팬에게 넘기기 | 함께 만든 것에 애착이 감 | 잔망루피 패러디 수용, 틴틴팅클 이름 질문, 한컴타자 인기투표 |

**그 밖의 참고**
- 망그러진곰(두산베어스 협업), 버터베어(지역 카페 홍보에서 시작): 지역 협업 사례
- 마루는 강쥐: 작품이 끝나도 캐릭터는 남음
- 라부부: 서사보다 가방에 다는 사용 방식이 반복 구매를 만듦 → 굿즈는 별도 설계가 필요함
- 브레드이발소: 초기의 거친 풍자에 항의가 있어 덜어냄 `발표` → 풍자는 약하게 시작

### 2-2. 어떻게 수익까지 갔나

| 사례 | 유명해진 계기 | 수익 장치 | 성과 |
|---|---|---|---|
| 구마몬 | 신칸센 개통 위기, 영업부장 설정, 깜짝 출현, 2011 대회 우승 | 승인 후 무료 사용, 식품 포장 | 2025 이용 상품 판매액 1,502.6억 엔 `발표` |
| 꿈돌이 | 2020 방송 우승, 디자인 개선 | 대전역 판매, 라면 등 협업 | 2024~2026.4 판매액 약 64.9억 원 `발표` |
| 부기 | 스토리, 해외 팬미팅 | 무상 개방 | 129개사 승인, 신청 19곳 → 32곳 `발표` |
| 하모 | 방언 이름, 한정 이모티콘, 팝업 | 상품·입점 확대 | 2026 상반기 1억 1,377만 원(전년비 105.9%) `발표` |
| 뚜비 | 탕후루 챌린지 26만 회, 댓글 소통 | 출시 직후 굿즈, 해외 대행 계약 | 18개월 2.18억 원 `미검증` |
| 조아용 | 이름 말장난, 2025 어워즈 대상 | 굿즈, 에버랜드 협업 | 2025 굿즈 3.8억 원 |
| 펭수 | 성인 대상 유머, 구체적 프로필 | 광고, 협찬, 라이선스 | 8개월 매출 101억 원 |
| 고양고양이 | 2012 SNS 장난이 퍼짐 | 수익 자료 없음 | 복귀 영상 260만 회, 설문 96% 아쉬움 |

**공통 조건 (`추론`)**
- 이름과 모티브에서 지역이 보임
- 캐릭터가 말하고 일함
- 무료 이모티콘, 쉬운 사용 허가처럼 문턱이 낮음
- 사람이 이미 오는 곳에서 팖
- 시민 애착과 지속 운영이 있음

### 2-3. 왜 실패했나

| 사례 | 결과 | 원인 |
|---|---|---|
| 서울 해치 | 약 32.3억 원 투입 후 쇼핑몰 폐쇄 | 시장 교체, 후속 예산 중단 |
| 서울 왕범이 | 7억여 원 투입 후 교체 | 정치적 판단 |
| 울산 해울이 | 상품 제작이 끊김 | 현수막·문서 중심 활용 |
| 전주시 | 11개 이상에 4.5억 원, 일부 권리 미확보 지적 | 권리 관리 부실 |
| 대구 패션이 | 현재 가치관·정책과 맞지 않음 | 시대 변화, 활용 미흡 |
| 경남이와 경이 등 | 만들고 방치 | 목적 불분명, 활용 계획 없음 |
| 고양고양이(2023 중단) | 인기가 있어도 퇴장, 2026년 복귀 | 단체장 교체 |

**교훈**
- 큰 예산이 답이 아니다: 해치 32억 원 vs 고양고양이 자체 제작
- 공통 원인: **단체장 의존, 활용 계획 부재, 권리 관리 부실**
- 시장 자체도 포화: 공공 캐릭터 525개(2018), 지자체 캐릭터 338개(2022), 일본 유루캐라 대회는 참가 수 54% 감소 후 2020년 종료

**→ 따라서** 대구 소품을 든 귀여운 수달만으로는 부족하다. 대구에서 충돌·결핍·관계를 찾고, 처음부터 판매 경로와 운영 계획을 함께 만들어야 한다.

## 3. 숫자로 본 기대효과와 한계

### 꿈돌이: 성장과 둔화 (`발표` 기반)

| 지표 | 변화 |
|---|---|
| IP 사용 신청 | 80건(2023) → 236건(2024) |
| 라이선스 수입 | 1,000만 원(2023) → 2,050만 원(2024) |
| 굿즈 판매액 | 9억 원(2024) → 16억 원(2025년 8월 말) |
| 라면 | 누적 123만 개, 18억 5,100만 원 (협업 상품의 약 56%) |
| 라면 월 판매량 | 50만 개(첫 달) → 약 4만 개(2025.10~2026.4 평균) |
| 협업 상품 월평균 | 약 3.8억 원 → 약 2.3억 원 (집계 범위가 달라 감소 폭은 불확실) |

### 구마몬: 판매액과 현 수입은 다르다

- 판매액: 2023년 1,663.9억 엔 → 2025년 1,502.6억 엔
- 2025년 감소액의 약 95%는 굿즈이고, 식품 비중은 76%(2023) → 약 89%(2025)로 쏠림
- 2년 경제효과 1,244억 엔(일본은행 지점 추계)의 입력값이 상품 판매액 1,250억 엔이며, 관광 효과는 12억 엔, 홍보 효과는 90억 엔
- 사용이 무료이므로 이 판매액은 현 수입이 아님

### 조회수와 수익

- 광고 수익 = 조회수 ÷ 1,000 × RPM → 조회수가 2배면 광고 수익도 2배
- 공공 채널은 수익이 0원일 수 있음 (충주시 사례)
- 쇼츠 예시: 100만 회의 창작자 몫 405달러 (경향신문 예시)
- 유튜브 신규 가입 기준은 2027년 2월부터 강화된다고 보도됨
- 한국 평균 RPM을 찾지 못해 조회수별 금액표는 아직 없음

### 우리 기획에 주는 결론 (`추론`)

- 숏폼은 **수익원이 아니라 인지와 애착을 만드는 수단**으로 평가한다
- 식품은 **인지 확장용**으로 쓰고, 초기 판매량을 지속 매출로 계산하지 않는다
- 기대효과는 판매액, 공공 수입, 홍보 효과를 나눠 적는다
- 기대 매출은 뚜비·하모 수준을 참고해 낮게 잡는다

**수치 사용 주의**
- 꿈돌이의 64.9억, 공공 판매처 35억, 협업 23억은 범위가 달라 합산 금지
- 시 수익 4%와 수수료 1~3%는 같은 기사에 있으나 4%의 적용 범위가 불명확
- 경제적 파급효과 4,000억 원은 산출 방식 미공개
- 사례별로 기간과 지표가 달라 순위로 쓰지 않음

## 4. 포지셔닝: 도달쑤를 어디에 둘 것인가

### 공식 프로필 (대구시 문서 「달쑤의 정체성」)

- 사는 곳: 대구 신천 / 생일: 2.21 대구시민의 날
- 취미: **유튜브하기, 참견하기**
- 특기: **수다(TMI)**, 춤·노래, 정의감·봉사정신, 수영
- 성격: 밝고 장난기 많음, 영리함, 환경에 관심, 이야기를 잘 듣고 공감함, ESFP
- 간식: **떡볶이와 함께 먹는 납작만두**
- 시의 방향: "일상생활을 하는 도달쑤의 에피소드를 통해 정체성(성격)을 만들어 감"
- 문서 작성 시기와 리뉴얼 후 변경 여부는 미확인

### 포지셔닝 제안 (허채연 안을 기반으로 수정)

| 항목 | 내용 |
|---|---|
| 타깃 | 1순위 대구를 찾는 2030, 2순위 출향민, 3순위 시민 (시험으로 확인) |
| 해결할 문제 | "대구는 볼 게 없다, 하루면 충분하다"는 인식 |
| 약속 | "도달쑤 따라가면 골목마다 먹을 게 있다" |
| 근거 | 대구 10미, 북성로·서문시장·동성로, 실제 신천 수달 |
| 말투 | 수다와 참견, "~했수달". 강한 사투리는 사장님 몫 |
| 차별점 | 하모=축제, 뚜비=생태 → **도달쑤=도시 골목·먹거리** |

**이미지 축 (`추론`)**
- 주축: 골목·먹거리
- 보조: 친환경 (신천 회차, 시 협업)
- 로봇 산업: 설정을 바꾸지 않고 회차 소재로만 사용

**대구 이미지의 근거 수준**
- 있음: "무뚝뚝하지만 인정 있다"는 평가(칼럼 수준)
- 부족: 더위·사투리·치맥을 대구 이미지로 측정한 조사
- 시 도시브랜드 조사(11월 22일까지) 결과가 나오면 다시 점검

## 5. 인물: 도달쑤 한 명 + 다양한 조연

### 옷이 바뀌어도 같은 도달쑤

**왜 바꾸나**
- 발표안은 베리에이션마다 특성과 설명을 만들고, 닮은 캐릭터가 관광지를 추천함
- 그러나 얼굴이 같아 성격 차이가 보이지 않고, 애착이 나뉘며, 설정 충돌을 관리해야 함
- 리뉴얼 전 시 매뉴얼에도 같은 도달쑤가 여러 직업복을 입은 포즈 7종이 있음

| 구조 | 장점 | 단점 |
|---|---|---|
| 별개 인격 (발표안) | 테스트 결과가 다양함, 최애 고르기 | 위 문제 |
| 친척·가족 | 여러 인격의 이유가 설명됨 | 구별 문제는 그대로, 설정을 넓혀 승인 부담 |
| 한 명 + 작업복 | 애착이 쌓임, 설정이 단순함 | 다양함이 줄어듦 |
| **한 명 + 작업복 + 다양한 조연 + 가끔 부캐 (추천)** | 장점 유지, 다양함 보완 | 조연 디자인 비용 |

**발표안의 대체**
- 베리에이션별 설명 → 일터 카드 (장소, 작업복, 소품, 상대 인물, 사고 소재)
- 닮은 마스코트 → 일터 배치 + 손발 맞는 사장님
- 베리에이션 최애 투표 → 조연 인기투표, 다음 작업복 투표
- 10미 굿즈 → 일터별 작업복 시리즈
- **잃는 것:** 캐릭터 수의 규모감
- **얻는 것:** 쌓이는 애착, 단순한 설정, 지난 회차를 잇는 재미, 우리 소유 조연 IP

- AI에 전부 맡기면 얼굴이 흔들림

- 16유형은 부담이 큼 → 일터 6~8곳, 결과 쏠림 사전 시험
- MBTI는 신뢰도 비판과 권리 주장 사례 → 결과에 쓰지 않고 "재미용" 표시
- TourAPI는 개발 계정 1,000건 → 후보 약 30곳을 미리 저장
- 대중교통 API 조건 미확인 → 동대구역·대구역·반월당 출발 경로를 미리 계산
- AI가 없는 장소를 지어낼 수 있음 → 추천은 규칙으로, AI는 말투만
- 측정: 완료 → 공유 → 코스 저장 → 현장 QR

## 10. 에이전트 4단계 재설계

### 큰 틀

- **순서 변경:** 생성 → 설정이 아니라 **설정 → 생성**. 그림이 먼저면 관계와 재미가 뒤에 억지로 붙음
- **공용 설정집:** 네 단계가 같은 인물, 장소, 일터 카드, **포지셔닝 규칙**을 사용
- **사람 검수:** 단계마다 승인 후 다음 단계
- **반응 순환:** 시청 반응이 다음 회차와 굿즈 결정으로 돌아옴

### 단계별

| 단계 | 개선 | 출력 예시 | 완료 기준 |
|---|---|---|---|
| 1. 관계·회차 설계 | 도달쑤 설정 고정, 상대 인물 다섯 칸, 일터 카드, 30초 대본 | "컷 4: 당황 표정 / 렌치 든 자세 / '됐다 마'" | 이름을 가린 대사로 인물을 맞힘 |
| 2. 장면 이미지 | 컷 지시로 파츠 합성, 표정·자세 추가, 공구 규칙 수정 | 숏폼용 컷 5장 | 공구골목 입력에만 공구가 나오고 얼굴이 동일 |
| 3. 알바 면접·코스 | 일터와 사장님 결과, 저장 데이터, 경로 사전 계산 | 호떡집 배치 / 경로 / 회차 / 공유 카드 | 없는 장소가 없고 결과가 쏠리지 않음 |
| 4. 반응 기반 굿즈 | 반응 좋은 표정·대사 선정, 일터 한정 시리즈, 업체 템플릿 | 키링 도안과 미리보기 | 입고 검수 통과 |

### 포지셔닝 반영 (허채연 제안, 조 피드백 3번)

- **고정 설정:** 4장 표를 `prompts.py`의 고정 규칙으로 추가 (제안 문서의 `원형캐릭터/설정.txt`는 현재 브랜치에 없음)
- **장면 규칙:** 모든 장면을 대구의 실제 골목·시장·음식과 연결
- **검수 항목:** 골목·먹거리·대구 지명이 드러나는가를 점수화 (원형 일치 검수 코드는 현재 찾지 못해 함께 신설)

### 첫 데모

- 범위: 서문시장, 북성로 공구골목, 수성못 3회차, 뚜비 1회 가상 출연
- 먼저 호떡집 회차로 성격 후보를 비교
- 결과: 대본 → 컷 이미지 → 면접 결과와 코스 → 스티커 도안

## 12. 전체 순환과 실행 순서

### 순환 구조

1. 숏폼·인스타툰으로 인물과 관계에 애착을 만든다
2. 표정 짤·이모티콘으로 일상 대화에 퍼뜨린다
3. 알바 면접으로 일터와 먹거리 코스를 제공한다
4. 회차 속 가게와 장소를 찾아간다
5. 이미 사람이 오는 곳에서 상품을 판다
6. 인기투표·사연이 다음 회차와 상품을 정한다 → 다시 1번

### 실행 순서

1. **먼저:** 시에 리뉴얼 후 매뉴얼과 이용 조건 확인, 팀 결정(13장), 수치 표 작성
2. **이어서:** 성격 시험, 관계도와 표정, 3회차 제작, 공구 규칙 수정
3. **반응이 있으면:** 이모티콘, 구별 캐릭터 협의, 면접 구현
4. **그다음:** 소량 굿즈, 가게 제휴, 지역 식품 협업
5. **나중:** 패밀리 공식화, 구단 콜라보

### 시험 지표

- 3회차 저장·공유 비율
- 짤의 2차 사용
- 어떤 조연이 언급되는가
- 테스트 완료 후 코스 저장 비율, 현장 QR 수

목표 수치는 비교 자료가 부족해 첫 3회 결과를 기준으로 정한다.
