# 표본 검사 기록 (10건)

- 검사 대상: id 1, 4, 7, 9, 12, 14, 16, 18, 19, 20 (임의 추출이 아니라 다양한 단계를 고르려고 직접 고른 목록)
- 대조 대상: `analysis/reviews.csv`의 요약문과 `analysis/reviews_tagged.csv`의 분류 값. 블로그·커뮤니티 원문은 이번 검사에서 다시 열지 않았음 [미검증]
- 기준: 단계 값과 감정 값이 요약문과 맞는지. 혼합은 중립(0)으로 분류.

| id | 단계 | 감정 | 대조 결과 | 조치 |
|---|---|---|---|---|
| 1 | 이동 | 0 | 맞음 (지하 통로 추천, 코스 조언) | 없음 |
| 4 | 둘러보기 | + | 맞음 (햇살 좋은 날, 둘레길 분위기) | 없음 |
| 7 | 먹기 | + | 맞음 (카레 우동 추천, 아늑함) | 없음 |
| 9 | 먹기 | 0 | 혼합 (흡연자 많아 실내 권함 언급). 혼합 규칙에 따라 중립 | 0으로 재분류 |
| 12 | 둘러보기 | + | 맞음 (저녁 바람·조명 좋음, 주탑 전망은 아쉬움) | 없음 |
| 14 | 둘러보기 | 0 | 혼합 (강바람이 세서 독서에 불편. 단풍·억새는 호평). 혼합 규칙에 따라 중립 | 0으로 재분류 |
| 16 | 먹기 | + | 맞음 (야키토리·재즈바 호평) | 없음 |
| 18 | 결제 | 0 | 맞음 (맛 무난, 선물 포장 강점) | 없음 |
| 19 | 알아보기 | 0 | 해소 (요약문에 불만 표현 없음, 정보 중심) | 팀 결정에 따라 −에서 0으로 재분류 |
| 20 | 둘러보기 | + | 맞음 (더운 날 실내 놀이 좋음) | 없음 |

## 결과
- 단계: 10건 중 10건 맞음.
- 감정: 10건 중 10건 맞음 (9, 14, 19는 재분류 후 기준에 맞음).
- 처음 작성한 초안은 19번을 "맞음"으로 적었으나 요약문 대조 결과 근거가 없었음. 팀 결정으로 0 재분류.
- 혼합 = 중립 규칙은 팀 결정으로 정함. 다른 리뷰 중 혼합 글이 있으면 같은 규칙으로 다시 봐야 함.
