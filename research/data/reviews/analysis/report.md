# 리뷰 분석 보고서 (3교시 시연, n=20)

- 기준 파일: `analysis/reviews.csv` (원문 요약 20건), `analysis/reviews_tagged.csv` (분류)
- 분류 방식: 여정 단계(6종), 주제(자유 입력), 감정(+, 0, −). 요약문 기준이며 원문 전체를 대조하지 않음 [미검증: 원문 대조는 표본 10건만 수행, `review_log.md`]
- 감정 규칙: 혼합(긍정과 불편이 함께 있는 글)은 중립(0)으로 분류.
- 표본 규칙: 건수 10 미만인 칸은 비율을 쓰지 않음. 차트: `analysis/charts/summary.html`
- 감정 분포: + 13, 0 7, − 0 (n=20)

## 1. 둘러보기 단계가 가장 많다 (n=10, 긍정 8건)
- 전체 20건 중 10건이 둘러보기 단계 (id 2, 3, 4, 5, 8, 10, 12, 13, 14, 20).
- 긍정 8건(3, 4, 5, 8, 10, 12, 13, 20), 중립 2건(2: 높이 무서움 언급, 14: 강바람 불편 언급).
- 해석: 리뷰의 중심은 산책·축제·실내 놀이 경험. 표본이 작아 일반화하지 않음.

## 2. 먹기 단계는 긍정 4건, 중립 1건이다 (n=5, 비율 없음)
- 대상: id 6(빙수), 7(카레 우동), 9(두류공원 분식·커피), 16(교동 야키토리·재즈바), 17(동성로 빵).
- 긍정 4건(6, 7, 16, 17). 중립 1건(9: 흡연자 많아 실내 이용 권함).
- 6번과 17번에도 웨이팅, 품절 등 불편 언급이 있으나 맛과 분위기 평가가 중심이라 긍정으로 둠.

## 3. 알아보기 단계는 3건이고 모두 정보형 또는 소개형이다 (n=3)
- 알아보기 단계: id 11(소개형, +), 15(정보형, 0), 19(정보형, 0).
- id 19는 팀 결정에 따라 부정(−)에서 0으로 재분류. 원문 요약(`reviews.csv` 19행)에 불만 표현이 없고, 보호자 결제와 사전 구매 정보가 중심이기 때문.

## 한계
- 20건은 시연용 표본. 여름 후기는 5건(6, 8, 11, 12, 20)뿐이라 여름 결론은 내지 않음.
- id 8과 id 11은 본문 일부 또는 소개형 글이라 감정 판단의 근거가 얕음.
- 주제가 "산책"과 "산책·공원"으로 나뉘어 있어 주제별 집계는 참고용.
