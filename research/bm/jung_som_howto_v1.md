# 대구 중구 발표 3·4장 빈칸 채우는 방법 v1

- 확인일: 2026-11-18
- 대상: 3장 중구 방문객 수, 4장 견적 단가. 두 항목은 로그인이나 직접 조회가 필요해서 조사 도구로는 채울 수 없습니다.
- 입력 파일: `research/bm/jung_som_inputs_v1.csv` (빈 `value` 칸에 값을 넣습니다)
- 구분 규칙: 찾은 값은 출처 URL과 확인일을 같은 행에 적고, `category`는 사실 / 가정 / 미검증 / 자료 없음 중 하나로 씁니다.

## 1. 3장: 중구 방문객 수 (데이터랩)

1. [한국관광 데이터랩 중구 페이지](https://datalab.visitkorea.or.kr/datalab/portal/loc/getAreaDataForm.do?SGG_CD=27110)를 엽니다.
2. 기간을 최근 3년(예: 2023-01 ~ 2025-12)으로 설정하고 월 단위 조회를 선택합니다. (화면 명칭은 페이지에서 확인)
3. 조회가 끝날 때까지 기다린 뒤 값을 읽습니다. 페이지에 "조회 중"이 남아 있으면 값이 아닙니다.
4. 기준은 **방문자(외부 방문자, 일 단위 중복 집계)**로 맞춥니다. 숙박·체류 탭 값과 섞지 않습니다.
5. CSV의 `A1_m_YYYY_MM` 행에 `value`를 넣고 `checked_date`를 적습니다.
6. 합계를 낼 때는 월별 값을 더하지 말고, 같은 기준 연간 값이 있으면 그 값을 씁니다. 중복 집계가 있어서 단순 합산은 총량이 아닙니다.

**지점 단위 대안**: [data.go.kr 15129927](https://www.data.go.kr/data/15129927/fileData.do)에서 `대구광역시_주요관광지점 입장객 통계` 파일의 중구 지점 행만 보면 됩니다. 파일 다운로드는 별도 승인 후 진행합니다.

## 2. 4장: 지자체 견적 단가 (나라장터)

1. [나라장터](https://www.g2b.go.kr)에 로그인합니다. 로그인하지 않으면 검색 결과를 볼 수 없습니다.
2. 입찰공고 검색 또는 낙찰정보 검색에서 기간을 2024~2026으로 설정합니다. (메뉴 명칭은 화면에서 확인)
3. 키워드를 아래 순서로 넣고 결과를 봅니다.
   - 대구 중구 관광
   - 관광 코스
   - 스탬프 투어
   - 관광 앱
4. 발주처가 대구광역시 중구청, 대구시, 대구문화예술진흥원, 대구관광재단 중 하나이고, 낙찰금액이 있는 건만 고릅니다.
5. 건마다 다음을 CSV의 `A4_bid_0X` 행에 적습니다.
   - 발주처, 사업명, 공고일
   - 추정가, 낙찰금액 (`value`에는 낙찰금액)
   - 용역 기간
   - 공고 URL
6. 과업지시서나 제안요청서에서 투입 인력과 기간을 찾아 `C5_hours_per_course`를 바꿉니다. 인력(명) × 기간(개월) × 월 근무시간(가정 160시간)으로 계산하고, 계산식을 `note`에 적습니다.

**주의**: 2025년 대구문화예술진흥원 SNS 채널 운영 용역(기초금액 277,999,000원)은 낙찰 결과가 없고 코스 제작이 아니므로, 견적 단가로 쓰지 않습니다.

## 3. 계산 방법

수익 구조가 지자체 협업만이라 v3부터 두 층으로 나눠 계산합니다 (`jung_summer_som_unit_economics_v3.md`). 아래 식은 계산 시트 `jung_som_model_v1.xlsx`에 수식으로 들어 있어, 「가정」 시트의 노란 칸만 바꾸면 다시 계산됩니다.

- 이용자 규모 (시장 근거, 매출 아님) = 여름 방문 연인원(`A1_m_2025_06~09` 합) × 도달 가능 비율 × `R_participation_rate`
- 연 매출 = `R_contract_price` × `R_contract_count`
- 계약 단가 = 코스 제작비 + `R_ops_monthly_price` × `R_ops_months` (운영이 과업에 있을 때만)
- 건당 비용 = `C5_hours_per_course` × `C4_min_wage_2026` + 운영 개월 × 월 클라우드 비용(`C2`) + 현장 운영비
- 손익분기 계약 건수 = `C6_dev_cost` ÷ (계약 단가 − 건당 비용), 올림

예: 계약 단가 1,500만 원(가정), 공수 40시간이면 15,000,000 ÷ (15,000,000 − 412,800) ≈ 1.03 → 2건. 낙찰가가 확인되면 `R_contract_price`만 바꿔 다시 계산합니다.

팀권 판매 식(손익분기 주문 수 = 고정비 ÷ (판매가 − 판매가 × 수수료율 − 건당 변동비))은 v2 기록으로 남기고, 팀이 민간 판매를 다시 정하기 전까지 쓰지 않습니다.

## 4. 입력 후 할 일

1. CSV에 값을 넣습니다.
2. `jung_summer_som_unit_economics_v3.md`의 2~4장 표를 입력값에 맞게 갱신합니다.
3. 발표 대본 3장·4장의 "아직 계산하지 못했다" 문구를 입력된 값으로 바꿉니다.

## 5. 남은 빈칸 찾는 방법 (2026-11-19 추가)

v3 노트 7장에서 비어 있는 세 항목을 찾는 경로입니다. 위에서부터 쉬운 순서입니다.

### 5-1. 대구 중구 계약 목록

1. **중구청 누리집에서 직접 찾습니다.** 계약정보공개 → [수의계약현황](https://www.jung.daegu.kr/new/pages/administration/page.html?mc=2377) → 계약명에 검색어를 넣고 **Enter로 검색**합니다. 검색 버튼(이미지)을 누르거나 빠르게 여러 번 조회하면 400 오류로 막힙니다 (2026-11-19).
   - "스탬프" 검색은 끝났습니다 (33건, 모두 물품·시설, 앱 운영 용역 없음. v3 7장).
   - 남은 검색어: "골목투어", "투어", "관광" (구분 = 용역). 시간 간격을 두고 하나씩 조회합니다.
2. **업체명으로도 찾습니다.** 동구·북구 운영사인 "댓츠잇", "댓츠잇소프트"를 업체명 칸에 넣으면 중구도 같은 업체를 쓰는지 바로 알 수 있습니다.
3. **지방재정365 누리집**([lofin365.go.kr](https://www.lofin365.go.kr))에서 "계약현황"과 "세부사업별 세출현황"을 엽니다. 둘 다 첫 화면 인기 검색어에 있는 메뉴입니다. 자치단체는 대구 중구, 연도는 2023~2026으로 고르고 관광 관련 세부사업을 봅니다. 2026-11-28(토) 08:00~24:00에는 서비스가 중단된다는 공지가 있습니다.
4. **공공데이터 API로 찾습니다** (5-3 참고). 계약 기록을 한 번에 모아 볼 때 씁니다.
5. **위 방법으로 안 나오면 정보공개청구를 합니다** (5-2의 청구 방법과 같음). 청구 대상 기관은 "대구광역시 중구"입니다.

### 5-2. 대구 스탬프 투어 참여자·완주자 수

1. **정보공개청구** ([정보공개포털 open.go.kr](https://www.open.go.kr)): 청구 대상은 대구광역시 동구·북구입니다. 아래 예시 문구를 그대로 써도 됩니다.
   - "2023~2026년 '동구네 놀러가자! 모바일 스탬프 투어'의 연도별 참여자 수, 스탬프 인증 횟수, 투어별 완주자 수, 완주 기념품 지급 수량, 운영 용역 과업지시서와 결과보고서"
   - 공개 여부는 청구를 받은 날부터 10일 안에 정하고, 10일 더 늘릴 수 있습니다. 비공개 결정에는 30일 안에 이의신청을 할 수 있습니다 ([동대문구 정보공개 안내](https://www.ddm.go.kr/www/contents.do?key=146), 2026-11-19 열람).
   - 운영 용역이 있으니 결과보고서에 참여 통계가 들어 있을 가능성이 큽니다 `[추정]`.
2. **구의회 회의록:** 동구의회·북구의회 회의록 검색에서 "스탬프"를 찾습니다. 행정사무감사와 예산 심사 때 실적을 묻는 경우가 많습니다 `[추정]`.
3. **기념품 수량으로 상한 잡기:** 동구 2026년 안내에는 완주 기념품이 에코백 250세트, 차량용 방향제 250세트(선착순 한정)로 나옵니다 ([한달살러 안내](https://www.monthler.kr/programs/328109644285214720)).
   - 같은 페이지에 운영 기간 6/15~11/30, 20개소, 모집 500명, 문의처 동구청 문화관광과가 함께 적혀 있습니다. 원문인 동구청 블로그는 직접 열지 못했습니다.
   - 2024년 제4회도 "투어별 250명 선착순"으로 같은 방식이었습니다 ([메트로신문 2024-06-11](https://www.metroseoul.co.kr/article/20240611500424), 2026-11-19 열람). 그래서 2026년 250세트는 `[추정: 2차 자료 + 전년 같은 방식]`으로 둡니다.
   - 계약금액으로 나누면 에코백 1개 약 15,600원, 방향제 1개 약 19,900원입니다 (계산). 기념품을 받은 완주자는 최대 약 500명이지만, 실제 완주자 수와는 다를 수 있습니다.
4. **운영사 문의:** 앱 운영사(댓츠잇)에 누적 통계를 물어볼 수 있습니다. 발주처 동의가 필요할 수 있습니다.
5. **다른 지역 참고값:** 부산 동구 2026 모바일 스탬프 투어는 39곳, 4개월 운영에 900여 명이 참여하고 1만 4천여 회 인증했습니다 ([브릿지경제 2026-11-16](https://www.viva100.com/article/20261116501013), 열람).

신청 순서:
1. 공공데이터포털에 회원가입하고, 위 상세 페이지에서 "활용신청"을 누릅니다.
2. 마이페이지에서 인증키를 확인합니다. 자동승인인지 심의인지는 상세 페이지에 표시됩니다 (이번 조회에서는 확인하지 못함).
3. 인증키는 저장소에 올리지 않습니다. 개인 PC의 환경변수나 `.env`에만 둡니다.
4. 나라장터 계약정보서비스는 7일 단위로 2023-01부터 현재까지 반복 조회한 뒤, 응답의 수요기관이 "대구광역시 중구"인 건만 고르고 계약명에 "스탬프"·"투어"·"관광"이 있는 건을 남깁니다.
5. 구청이 나라장터를 거치지 않은 소액 수의계약은 이 API에 없을 수 있습니다 `[추정]`. 그때는 5-1의 구청 누리집이나 지방재정365 계약현황 API로 확인합니다.
