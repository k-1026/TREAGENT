# 채점 기준 초안 (크리에이티브 소재)

- 상태: **초안 · 팀 검토 전**. 1·3·5점 문장을 팀이 확정해야 합니다.
- 근거 규칙: 점수마다 근거 id 1개 이상 (`archive/inventory/top3_rationale.md`의 채점 방식).

| 기준 | 1점 | 3점 | 5점 | 근거 |
|---|---|---|---|---|
| 스토리성 | 이름과 위치만 있음 | 근거 자료에 인물·사건 1개 | 여러 출처에서 일관되게 반복 | 근거 id 필요 |
| 캐릭터 확장성 | 의인화할 대상이 없음 | 고유한 이름·성격이 있음 | 수집물에 반복 등장 | 근거 id 필요 |
| 웰니스·안전 연계 | 연결 없음 | 쉼터·그늘과 간접 연결 | 실내·그늘 경험과 직접 연결 | 근거 id 필요 |

- 가중치: 스토리성 40%, 캐릭터 확장성 30%, 연계 30% (창작 후보, 팀 결정).
- 판정 기준: 점수가 아니라 근거 id를 먼저 확인합니다.
