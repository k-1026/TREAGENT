# 지자체 스탬프 투어 — 단계와 이해관계자 (v1)

- 작성일: 2026-11-11
- 분석 대상: 지자체·공공기관이 운영하는 걷기 스탬프 투어 (한 기업이 아니라 "사업 형식" 한 줄기)
- 기준 사례 3개 (근거가 가장 많은 순)
  - 국가유산 방문자 여권 투어 (국가유산청·국가유산진흥원) (`tour_cases.md:78`, `:150`)
  - 대구 '스탬프 로드 20' / 대구 모바일 스탬프투어 (대구문화예술진흥원 관광본부, 캐시워크 연동) (`tour_cases.md:73`, `:89`)
  - 도봉구 '도봉꾹꾹 스탬프여행' (도봉구청) (`tour_cases.md:90`)
- 표기: **굵게** = 하는 사람, (괄호) = 영향 주는 사람, `[U]` = 이름 미확인, `[I]` = 해석, 🟦 = 팀 자산이 들어가는 칸
- 약어: `tour_cases.md` = `research/daegu_history_tour_cases.md`

## 1. 활동 후보 (동사 + 목적어)

| 단계 | 활동 | 근거 |
|---|---|---|
| ① 기획·거점 선정 | 거점(관광지) 20곳·10곳·76곳을 고른다 | `tour_cases.md:73`, `:89`, `:90`, `:150` |
| ① 기획·거점 선정 | 완주 조건과 보상을 정한다 | 도봉 10곳 완주 → 기록장 (`:90`) |
| ② 인증 도구 제작 | 앱 QR·위치 인증을 만든다 | 도봉 앱 QR (`:90`), 캐시워크 연동 (`:89`) |
| ② 인증 도구 제작 | 실물 여권·도장 용지·도장을 찍어 낸다 | 국가유산 여권·도장 용지 (`:78`) |
| ③ 신청·배포 | 여권을 선착순으로 신청받고 배포한다 | 특별여권 8만 부 하루 소진 (`:151`), 여권1 5,000부 소진 (`:155`) |
| ③ 신청·배포 | 언론·SNS로 알린다 | 대구MBC 보도 (`:89`), 인스타그램·카카오 채널 안내 (`:78`) |
| ④ 방문·인증 | 거점을 방문해 도장·QR로 인증한다 | `:73`, `:78`, `:90` |
| ④ 방문·인증 | 주변 가게를 이용한다 `[I]` | 상권형 사례(을지명보)만 확인 (`:74`) |
| ⑤ 완주·보상·기록 | 완주 인증 후 기념품·기록장을 준다 | `:78`, `:90` |
| ⑤ 완주·보상·기록 | 탐방록(후기)을 쓴다 | 도봉 (`:90`) |
| 지원 · 기술 | 캐시워크 캐시 연동 | `:73` |
| 지원 · 조달 | 여권·기념품 인쇄·제작 용역 `[U]` | 제작 업체 이름은 자료에 없음 |
| 지원 · 인프라 | 공공 예산 `[U]` | 예산 규모는 자료에 없음 |

## 2. 단계 5개 (팀 확정 전 초안)

기획·거점 선정 → 인증 도구 제작 → 신청·배포 → 방문·인증 → 완주·보상·기록

- 교과서 단계와의 대응: 원천·소싱 / 가공·제작 / 플랫폼·유통 / 주문·구매 / 전달·서비스
- 차이: 일반 커머스와 달리 **돈의 시작점이 소비자가 아니라 공공 예산**이다 `[I]` (참여비 유무는 자료에 없음 `[U]`)
