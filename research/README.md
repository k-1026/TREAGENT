기업·기관 조사 자료는 `company/<이름>/`의 `onepager.md`와 `sources.md`에서 확인한다. 여러 사례의 흐름과 병목을 비교한 결과는 `valuechain/`, CSV와 데이터 단위의 검증 기록은 `data/`에서 확인한다. 사업 모델이나 기능을 논의할 때는 해당 문서와 근거 데이터의 경로를 함께 남긴다.
