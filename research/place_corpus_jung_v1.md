# 중구 장소 이야기 코퍼스 v1 (RAG용 검수 자료 초안)

- 작성일: 2026-11-27 · 확인일: 2026-11-27 (모든 웹 출처는 이날 직접 열어 읽음)
- 상태: **초안**. 팀 사실 대조(RES) 전입니다. 확정 자료가 아닙니다.
- 목적: 기술 명세 15-4장 "RAG (검수 자료 검색)"의 코퍼스 형식(장소 ID, 문장, 출처, 확인일, 주의 표시)으로 장소 이야기 근거를 모읍니다 (plan/spec/treagent_tech_spec_v1.md:1167-1186).
- 범위: 중구 장소 DB 50곳(J01~J50) (dev/supabase/migrations/seed_places.sql, seed_places_jung.sql, research/tourism_data/tourism_data_jung_v7.xlsx 「중구 장소표」).
- 이 문서가 다루지 않는 것: 운영 시간·휴관·요금 같은 **변하는 사실**. 그건 장소 DB 조회 도구의 일입니다 (treagent_tech_spec_v1.md:1094). 아래에서 운영 정보가 나오면 DB 값과 **충돌을 알리는 용도**로만 적었습니다.

## 0. 쓰는 법

- 문장 ID: `장소ID-번호` (예: `J10-02`). 앱의 "이야기와 출처 보기"에는 이 ID와 출처 ID를 같이 보여 줍니다.
- 출처 ID: `S01`~`S26`은 웹 페이지, `R`로 시작하는 것은 저장소 파일입니다. 목록은 맨 아래 `## 출처`에 있습니다.
- 표시
  - `주의`: 식민지 시기·박해·처형 등 민감한 역사 소재. 공포·참사 연출에 쓰지 않습니다 (CLAUDE.md 민감한 소재).
  - `[충돌]`: 출처끼리 값이 다릅니다. 팀이 하나로 정하기 전에는 문장에 숫자를 넣지 않습니다.
  - `[확인 필요]`: 검색 결과에만 있고 원문을 열어 확인하지 못했습니다. 코퍼스에 넣지 않습니다.
- 문장은 출처를 바꿔 쓴 것입니다. 원문을 그대로 옮기지 않았습니다.
