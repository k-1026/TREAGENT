# 앱 화면 목업 반영 설계 v1 (1단계: 타이틀)

상태: 승인 대기 (승인 전에는 앱 코드를 고치지 않는다)
브랜치: `feat/app-title-screen` (origin/dev 기준)

## 의도와 이유
- 목업(`storyboard/app_login_region_mockup_v1.html`, `contrast_compare_v1.html`, `home_candidates_v1.html`)대로 앱 화면을 화면 순서대로 바꾼다.
- 1단계는 목업에만 있는 타이틀 화면을 추가한다. 로그인 전 첫 화면이다.

## 목표
- 로그인하지 않은 사용자가 처음 보는 화면을 `/title`로 만든다.
- 타이틀의 두 버튼(바람 장부 열기 → 로그인, 처음이에요 → 가입)으로 기존 화면에 간다.
- 색 토큰은 `src/lib/theme.ts`의 값을 목업 값으로 맞춘다 (빨강 `#dc3b30` → 권장 `#d03a2f`는 결정 필요, 아래 참고).

## 비목표
- 로그인·가입·위치 화면의 모양 변경 (2~3단계에서 한다).
- 홈 빈 자리 후보 적용 (팀 결정 전이라 하지 않는다).
- 실제 그림 에셋 제작 (장부·꼬리·능금은 목업의 임시 도형을 그대로 쓴다).

## 제약
- 기존 `_layout.tsx` 게이트: 로그아웃 상태에서 `/login`·`/signup`이 아니면 `/login`으로 보낸다. 타이틀을 넣으려면 이 규칙을 `/title`도 허용하도록 바꿔야 한다.
- Expo SDK 58 문서를 먼저 확인한다 (`dev/app/AGENTS.md`).
- 새 라이브러리 설치는 하지 않는다 (React Native 기본 기능으로 만든다).

## 접근 방식
- A. 목업의 CSS 애니메이션(바람·꼬리·능금 굴러오기)을 `Animated`로 옮긴다. 살아 있는 느낌은 가장 잘 살지만 코드가 늘어난다.
- B. 정적 화면으로 만들고 애니메이션은 뺀다. 가장 단순하지만 목업과 달라진다.
- 추천: A의 핵심 연출(장부 위 바람선 한 번, 능금 굴러오기)만 옮긴다. 나머지는 뺀다.

## 내가 정한 것 (확인 필요 표시)
- 경로: `src/app/title.tsx`, 주소 `/title`. [내 판단]
- 색: `theme.ts` 값은 이번 단계에서 바꾸지 않는다. 타이틀에 필요한 색만 목업 값으로 쓴다. [내 판단]
- 임시 도형 SVG는 `src/components/`에 둔다. 나중에 실제 그림으로 바꾼다. [내 판단]
- 로그인 상태에서는 타이틀을 보여 주지 않는다 (기존 리다이렉트 규칙 유지). [내 판단]

## 결정 필요
- 빨강 버튼 색: `#dc3b30`(기존, 대비 4.46 미달) 또는 `#d03a2f`(권장, 대비 4.85). 전체 화면에 영향이 크므로 팀이 정한다. 이번 단계는 타이틀 버튼에만 `#d03a2f`를 쓰고, 나머지는 기존 값을 둔다.
- 버튼 문구 후보 A(바람 장부 열기 / 처음이에요)와 B(로그인 / 시작하기) 중 기본값.

## 완료 기준
- `npx tsc --noEmit`, `npx expo lint` 통과
- 로그아웃 상태에서 앱을 열면 타이틀이 보이고, 두 버튼이 각각 로그인·가입으로 이동한다.
- 미리보기에서 화면을 캡처해 확인한다.
